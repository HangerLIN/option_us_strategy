### 步骤2: 回填盘前数据（09:25-09:30）

```bash
# 重要: 需要前一天的数据来计算 prev_close_rth
# 所以 start 要往前推1-3天

python -m scripts.backfill_premarket_window \
  --start 2025-09-30 \
  --end 2025-10-06 \
  --universe ref_market_cap:GLOBAL \
  --window-start 09:24 \
  --window-end 09:30 \
  --batch-size 10
```

```bash

  --batch-size 10 \
  --rth-only 1
```

## ⚠️ 常见问题

### 问题1: IBKR连接失败

**错误**: `Unable connect as the client id is already in use`

**解决**:
```bash
# 杀掉所有占用IBKR连接的进程
pkill -9 -f "python.*ingest"
pkill -9 -f "python.*backfill"

# 等待5秒后重试
sleep 5
```

### 问题2: 盘前数据缺失09:25

**症状**: 只有09:26-09:30，缺少09:25

**原因**: `--window-end` 设置为 09:31，导致拉取 [09:26, 09:31]

**解决**: 使用 `--window-start 09:24 --window-end 09:30`

### 问题3: 指标计算很慢

**原因**: `_recompute_indicators` 会重新计算整天的所有指标

**优化**: 
- 减小 `--batch-size`（避免超时）
- 分批执行（每次5-10只股票）
- 或者在非交易时段运行

### 问题4: 时区错误

**症状**: IBKR 日志显示 `end=13:31 US/Eastern`（应该是09:31）

**原因**: `libs/infra/ibkr_client.py` 的时区转换 Bug

**已修复**: 现在会先转换到 ET 时区再格式化

## 💡 优化建议

1. **分批执行**: 使用 `--batch-size 5-10` 避免IBKR速率限制
2. **增量更新**: 已有数据的日期会自动跳过（upsert机制）
3. **并行处理**: 不同交易日可以分开执行后合并
4. **错误恢复**: 脚本支持断点续传，失败后重新运行即可
