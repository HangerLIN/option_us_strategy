**订阅的数据类型**:
- **Tick Price**: bid, ask, last
- **Tick Size**: bidSize, askSize, lastSize
- **RTVolume** (Tick 58): `price;size;time;totalVolume;VWAP;single`

**术语解释**：
- **Tick Price** - 价格类Tick数据，包含三种报价
  - `bid`：买方最高报价（买1价）
  - `ask`：卖方最低报价（卖1价）
  - `last`：最新成交价格
- **Tick Size** - 数量类Tick数据，对应三种报价的数量
  - `bidSize`：买1挂单数量（合约数）
  - `askSize`：卖1挂单数量（合约数）
  - `lastSize`：最近一笔成交数量（合约数）
- **RTVolume** - 实时成交量数据（第58个通用Tick），包含：
  - `price`：成交价格
  - `size`：成交数量
  - `time`：成交时间戳（Unix格式）
  - `totalVolume`：当日累计成交量
  - `VWAP`：成交量加权平均价（Volume Weighted Average Price）
  - `single`：是否为单笔成交标志

### 2.3 分钟K线聚合

#### 2.3.1 聚合逻辑
```python
async def _aggregate_symbol(symbol):
    """对单个标的进行分钟级聚合"""
    buffer = {
        'open': None,
        'high': float('-inf'),
        'low': float('inf'),
        'close': None,
        'volume': 0,
        'ticks': []
    }
    current_minute = None
    
    while True:
        tick = await queue.get()
        tick_time = datetime.fromtimestamp(tick['time'], tz=EASTERN)
        tick_minute = tick_time.replace(second=0, microsecond=0)
        
        # 分钟切换：闭合上一分钟
        if current_minute and tick_minute > current_minute:
            ts_end = current_minute + timedelta(minutes=1)
            
            # 如果该分钟有成交
            if buffer['ticks']:
                bar = {
                    'symbol': symbol,
                    'ts_end': ts_end,
                    'open': buffer['open'],
                    'high': buffer['high'],
                    'low': buffer['low'],
                    'close': buffer['close'],
                    'volume': buffer['volume'],
                    'session': determine_session(ts_end)  # RTH/PMO/AMO
                }
            else:
                # 无成交：使用NBBO mid填充
                mid = (self._quotes[symbol].bid + self._quotes[symbol].ask) / 2
                bar = {
                    'symbol': symbol,
                    'ts_end': ts_end,
                    'open': mid,
                    'high': mid,
                    'low': mid,
                    'close': mid,
                    'volume': 0,
                    'session': determine_session(ts_end)
                }
            
            # 持久化K线
            await self._persist_bar(bar)
            
            # 计算指标
            await self._update_indicators(symbol, ts_end)
            
            # 发布事件
            await self._broadcast_bar_closed(symbol, ts_end)
            
            # 重置缓冲区
            buffer = reset_buffer()
        
        # 累积当前分钟的tick
        current_minute = tick_minute
        if buffer['open'] is None:
            buffer['open'] = tick['price']
        buffer['high'] = max(buffer['high'], tick['price'])
        buffer['low'] = min(buffer['low'], tick['price'])
        buffer['close'] = tick['price']
        buffer['volume'] += tick['size']
        buffer['ticks'].append(tick)
```

> **💡 关键设计说明：为什么实盘要自己聚合Tick，而不是直接订阅IBKR的实时K线？**
>
> **实盘系统（rt_engine）：Tick聚合方式**
> - ✅ **极低延迟**：分钟整点（如09:31:00.000）立即触发信号生成，延迟<100ms
> - ✅ **时间精确控制**：自主掌握分钟闭合时刻，不依赖IBKR推送时延（2-5秒）
> - ✅ **无成交处理**：无tick时使用NBBO mid填充，保证每分钟都有K线
> - ✅ **缺口检测**：实时检测数据缺失，自动补充≤15分钟缺口
> - ✅ **多数据源融合**：同时聚合股票+期权+VIX，统一时间戳对齐
> - ✅ **自定义指标**：RVOL等需要实时累积计算的指标
>
> **回测/数据准备（backtest）：历史K线API方式**
> - 📊 使用 `req_historical_1m_equity()` 批量拉取已聚合的历史K线
> - 📊 IBKR服务器已完成聚合，数据质量有保证
> - 📊 不需要实时性，适合批量导入历史数据
> - 📊 节省API调用频率（避免每个tick都请求）
>
> **数据流对比**：
> ```
> 实盘：IBKR Tick Stream → MinuteAggregator → 实时聚合OHLCV → bars_closed事件 → 信号生成
> 回测：IBKR Historical API → 批量获取K线 → 存入DB → 回测时读取 → 信号重算
> ```
>
> **核心差异**：实盘追求**毫秒级实时性**，回测追求**批量高效导入**。

```python
async def _update_indicators(session, symbol, ts_end):
    """为最新K线计算13个技术指标"""
    
    # 1. 读取最近120根K线（足够计算所有指标）
    rows = session.execute("""
        SELECT ts_end, open, high, low, close, volume
        FROM bars1m_equity
        WHERE symbol = :symbol AND ts_end <= :ts_end
        ORDER BY ts_end DESC
        LIMIT 120
    """, {'symbol': symbol, 'ts_end': ts_end}).fetchall()
    
    if len(rows) < 30:  # 最小窗口检查
        return
    
    # 2. 转换为DataFrame（倒序变正序）

    baseline_map = self._get_baseline_map(session, symbol)

    indicators = compute_indicator_row(df, baseline_map)

        INSERT INTO indicators_eq_1m (
            symbol, ts_end, 
            rsi6, rsi12, rsi24,
            atr14, ao, cci14, cci6,
            obv, obv_ema20,
```

#### 2.4.2 指标定义详解

```python
def compute_indicator_row(df: pd.DataFrame, baseline_map: Dict) -> Dict:
    """
    计算13个技术指标（最新一行）
    
    参数:
        df: 至少30行的OHLCV数据（时间升序）
        baseline_map: {minute_index: mean_vol_20d} RVOL基线
    
    返回:
        Dict包含13个指标的最新值
    """
    
    # ========== 1. RSI (相对强弱指标) ==========
    # 用途：超买超卖判断
    rsi6 = ta.momentum.RSIIndicator(df['close'], window=6).rsi().iloc[-1]
    rsi12 = ta.momentum.RSIIndicator(df['close'], window=12).rsi().iloc[-1]
    rsi24 = ta.momentum.RSIIndicator(df['close'], window=24).rsi().iloc[-1]
    
    # ========== 2. ATR (平均真实波幅) ==========
    # 用途：止损距离、轻微反弹幅度判断
    atr14 = ta.volatility.AverageTrueRange(
        high=df['high'],
        low=df['low'],
        close=df['close'],
        window=14
    ).average_true_range().iloc[-1]
    
    # ========== 3. AO (动量震荡指标) ==========
    # 用途：主过滤规则"AO>0且上行"
    ao = ta.momentum.AwesomeOscillatorIndicator(
        high=df['high'],
        low=df['low'],
        window1=5,
        window2=34
    ).awesome_oscillator().iloc[-1]
    
    # ========== 4. CCI (商品通道指标) ==========
    # 用途：主过滤规则"CCI14>0 & CCI6>0"
    cci14 = ta.trend.CCIIndicator(
        high=df['high'],
        low=df['low'],
        close=df['close'],
        window=14
    ).cci().iloc[-1]
    
    cci6 = ta.trend.CCIIndicator(
        high=df['high'],
        low=df['low'],
        close=df['close'],
        window=6
    ).cci().iloc[-1]
    
    # ========== 5. OBV + EMA20 ==========
    # 用途：主过滤规则"OBV>EMA20"，量价确认
    obv_series = ta.volume.OnBalanceVolumeIndicator(
        close=df['close'],
        volume=df['volume']
    ).on_balance_volume()
    
    obv = obv_series.iloc[-1]
    obv_ema20 = obv_series.ewm(span=20, adjust=False).mean().iloc[-1]
    
    # ========== 6. Stochastic (随机指标) ==========
    # 用途：附加过滤"Stoch_K上穿Stoch_D且K<80"
    stoch = ta.momentum.StochasticOscillator(
        high=df['high'],
        low=df['low'],
        close=df['close'],
        window=14,
        smooth_window=3
    )
    stoch_k = stoch.stoch().iloc[-1]
    stoch_d = stoch.stoch_signal().iloc[-1]
    
    # ========== 7. MFI (资金流量指标) ==========
    # 用途：附加过滤"MFI14>50且斜率>0"
    mfi14 = ta.volume.MFIIndicator(
        high=df['high'],
        low=df['low'],
        close=df['close'],
        volume=df['volume'],
        window=14
    ).money_flow_index().iloc[-1]
    
    # ========== 8. RVOL (相对成交量) ==========
    # 用途：盘前量价确认、回补买入过滤
    rvol6 = _compute_rvol_series(df, baseline_map, window=6).iloc[-1]
    
    return {
        'rsi6': rsi6,
        'rsi12': rsi12,
        'rsi24': rsi24,
        'atr14': atr14,
        'ao': ao,
        'cci14': cci14,
        'cci6': cci6,
        'obv': obv,
        'obv_ema20': obv_ema20,
        'stoch_k': stoch_k,
        'stoch_d': stoch_d,
        'mfi14': mfi14,
        'rvol6': rvol6 if not pd.isna(rvol6) else None
    }


def _compute_rvol_series(df, baseline_map, window=6):
    """
    计算相对成交量（滚动6分钟均量 / 20日同时段分时基线）
    """
    rvol_values = []
    
    for i in range(len(df)):
        ts_end = df.iloc[i]['ts_end']
        et_time = ts_end.astimezone(EASTERN)
        minute_index = et_time.hour * 60 + et_time.minute
        
        # 从基线字典获取该时段的历史均量
        baseline_vol = baseline_map.get(minute_index)
        
        if baseline_vol is None or baseline_vol == 0:
            rvol_values.append(np.nan)
            continue
        
        # 计算最近window分钟的均量
        start_idx = max(0, i - window + 1)
        recent_vols = df.iloc[start_idx:i+1]['volume']
        avg_vol = recent_vols.mean()
        
        # RVOL = 当前均量 / 历史同时段均量
        rvol = avg_vol / baseline_vol
        rvol_values.append(rvol)
    
    return pd.Series(rvol_values, index=df.index)
```

### 2.5 RVOL基线自动刷新

> **每日16:10自动触发，保持基线数据最新**

```python
async def _maybe_refresh_rvol_baseline(self, ts_end):
    """
    检查是否需要刷新RVOL基线
    触发条件：美东时间16:10
    """
    et = ts_end.astimezone(EASTERN)
    
    if et.hour == 16 and et.minute == 10:
        trade_date = et.date()
        await self._refresh_rvol_baseline(trade_date)


async def _refresh_rvol_baseline(self, trade_date):
    """
    刷新所有活跃标的的RVOL基线
    
    流程：
    1. 拉取近40个交易日的1分钟K线
    2. 按分钟索引（HH:MM）分组
    3. 计算每个时段的20日均量
    4. 写入rvol_baseline_eq表
    """
    session = self.session_factory()
    try:
        active_symbols = dao.get_active_symbols(session)
        
        for symbol in active_symbols:
            LOGGER.info(f"refresh_rvol_baseline.start", symbol=symbol)
            
            # 计算回溯时间（40个交易日）
            trading_days = dao.get_trading_days(session, count=40, before=trade_date)
            start_date = trading_days[0]
            end_date = trade_date
            
            # 从IBKR拉取历史数据
            bars = self.ib_client.req_historical_1m(
                symbol=symbol,
                start=start_date,
                end=end_date,
                use_rth=True  # 仅常规交易时段
            )
            
            if not bars:
                LOGGER.warning("refresh_rvol_baseline.no_data", symbol=symbol)
                continue
            
            # 转换为DataFrame
            df = pd.DataFrame(bars)
            df['ts_end'] = pd.to_datetime(df['ts_end'])
            df['minute_index'] = df['ts_end'].apply(
                lambda x: x.astimezone(EASTERN).hour * 60 + x.astimezone(EASTERN).minute
            )
            
            # 按分钟索引分组，计算20日均量
            baseline = df.groupby('minute_index')['volume'].apply(
                lambda x: x.rolling(window=20, min_periods=10).mean().iloc[-1]
            ).to_dict()
            
            # 批量写入数据库
            for minute_index, mean_vol in baseline.items():
                session.execute("""
                    INSERT INTO rvol_baseline_eq (symbol, minute_index, mean_vol_20d, updated_at)
                    VALUES (:symbol, :minute_index, :mean_vol, NOW())
                    ON CONFLICT (symbol, minute_index) 
                    DO UPDATE SET mean_vol_20d = EXCLUDED.mean_vol_20d, updated_at = NOW()
                """, {
                    'symbol': symbol,
                    'minute_index': minute_index,
                    'mean_vol': mean_vol
                })
            
            session.commit()
            
            # 更新内存缓存
            self._baseline_cache[symbol] = baseline
            
            LOGGER.info("refresh_rvol_baseline.success", symbol=symbol, points=len(baseline))
    
    finally:
        session.close()
```

### 2.6 自动缺口检测与回补

```python
async def _check_and_backfill(self, symbol, current_ts):
    """
    检测K线缺口并自动回补
    
    触发条件：当前分钟与上次持久化分钟间隔>1分钟
    补数窗口：≤15分钟自动补；>15分钟仅告警
    """
    last_ts = self._last_persisted.get(symbol)
    
    if not last_ts:
        return
    
    gap_seconds = (current_ts - last_ts).total_seconds()
    gap_minutes = int(gap_seconds / 60) - 1
    
    if gap_minutes <= 0:
        return  # 无缺口
    
    LOGGER.warning(
        "data_quality.gap_detected",
        symbol=symbol,
        gap_minutes=gap_minutes,
        last_ts=last_ts.isoformat(),
        current_ts=current_ts.isoformat()
    )
    
    # 缺口过大：仅告警，不补数
    if gap_minutes > 15:
        LOGGER.error(
            "data_quality.gap_too_large",
            symbol=symbol,
            gap_minutes=gap_minutes
        )
        # 写入风险事件
        dao.write_risk_event(
            event_ts=current_ts,
            event_code='DATA_GAP_TOO_LARGE',
            severity='ERROR',
            symbol=symbol,
            payload={'gap_minutes': gap_minutes}
        )
        return
    
    # 自动回补
    try:
        LOGGER.info("data_quality.backfill_start", symbol=symbol, gap_minutes=gap_minutes)
        
        # 从IBKR拉取缺失的K线
        bars = self.ib_client.req_historical_1m(
            symbol=symbol,
            start=last_ts + timedelta(minutes=1),
            end=current_ts - timedelta(minutes=1),
            use_rth=True
        )
        
        if not bars:
            LOGGER.warning("data_quality.backfill_no_data", symbol=symbol)
            return
        
        session = self.session_factory()
        try:
            # 逐根K线持久化+计算指标
            for bar in bars:
                # 写入bars1m_equity
                self._persist_bar_sync(session, bar)
                
                # 计算并写入indicators_eq_1m
                self._update_indicators_sync(session, symbol, bar['ts_end'])
            
            session.commit()
            
            LOGGER.info(
                "data_quality.backfill_success",
                symbol=symbol,
                filled_bars=len(bars)
            )
        finally:
            session.close()
    
    except Exception as exc:
        LOGGER.exception(
            "data_quality.backfill_failed",
            symbol=symbol,
            error=str(exc)
        )
```

```python
    def _apply_filters(self, session, symbol, premarket_gain, trade_date):
        """
        应用过滤条件（对应F0｜候选池）
        
        必须满足：
        1. 市值≥$100B（做看涨）或≥$20B（其他操作）
        2. 日线M60上行（Close>SMA60且斜率>0）
        
        可选（feature.premarket_volume_filter=true时）：
        3. OBV斜率>0 或 OBV>EMA20
        4. RVOL(6)≥1.5
        """
        
        # ========== 1. 市值过滤 ==========
        marketcap = session.execute("""
            SELECT market_cap FROM ref_market_cap_snapshot
            WHERE symbol = :symbol
            ORDER BY snapshot_date DESC
            LIMIT 1
        """, {'symbol': symbol}).scalar()
        
        if not marketcap:
            return False
        
        # 根据操作类型判断市值阈值
        min_marketcap = 100_000_000_000  # $100B for call options
        if marketcap < min_marketcap:
            LOGGER.debug("top5.filter_marketcap_fail", symbol=symbol, marketcap=marketcap)
            return False
        
        # ========== 2. 日线趋势过滤 ==========
        # 获取最近60个交易日的日线数据
        daily_bars = session.execute("""
            SELECT close FROM bars_daily
            WHERE symbol = :symbol
            ORDER BY trade_date DESC
            LIMIT 60
        """, {'symbol': symbol}).fetchall()
        
        if len(daily_bars) < 60:
            return False
        
        closes = [row[0] for row in daily_bars][::-1]  # 倒序变正序
        sma60 = sum(closes[-60:]) / 60
        latest_close = closes[-1]
        
        # 计算SMA60斜率（最近5日）
        if len(closes) >= 65:
            sma60_5d_ago = sum(closes[-65:-5]) / 60
            sma60_slope = (sma60 - sma60_5d_ago) / 5
        else:
            sma60_slope = 0
        
        # M60上行：收盘价>SMA60 且 斜率>0
        if latest_close <= sma60 or sma60_slope <= 0:
            LOGGER.debug("top5.filter_trend_fail", symbol=symbol, close=latest_close, sma60=sma60, slope=sma60_slope)
            return False
        
        # ========== 3. 盘前量价确认（可选） ==========
        if self.settings.feature_premarket_volume_filter:
            # 拉取盘前时段（09:00-09:25）的分钟K线
            premarket_bars = session.execute("""
                SELECT ts_end, close, volume FROM bars1m_equity
                WHERE symbol = :symbol
                  AND ts_end::date = :trade_date
                  AND ts_end BETWEEN :start AND :end
                ORDER BY ts_end ASC
            """, {
                'symbol': symbol,
                'trade_date': trade_date,
                'start': datetime(trade_date.year, trade_date.month, trade_date.day, 9, 0, tzinfo=EASTERN),
                'end': datetime(trade_date.year, trade_date.month, trade_date.day, 9, 25, tzinfo=EASTERN)
            }).fetchall()
            
            if len(premarket_bars) < 6:
                return False
            
            # 计算OBV
            obv_values = []
            obv = 0
            for i, (ts_end, close, volume) in enumerate(premarket_bars):
                if i == 0:
                    obv_values.append(0)
                    continue
                
                prev_close = premarket_bars[i-1][1]
                if close > prev_close:
                    obv += volume
                elif close < prev_close:
                    obv -= volume
                
                obv_values.append(obv)
            
            # OBV斜率（线性回归）
            obv_slope = (obv_values[-1] - obv_values[0]) / len(obv_values)
            
            # OBV EMA20（如果有足够数据）
            # 这里简化：直接判断斜率>0
            if obv_slope <= 0:
                LOGGER.debug("top5.filter_obv_fail", symbol=symbol, obv_slope=obv_slope)
                return False
            
            # 计算RVOL(6)
            baseline_map = dao.fetch_rvol_baseline(session, symbol)
            if not baseline_map:
                return False
            
            recent_vols = [bar[2] for bar in premarket_bars[-6:]]
            avg_vol = sum(recent_vols) / len(recent_vols)
            
            # 09:25的分钟索引
            minute_index = 9 * 60 + 25
            baseline_vol = baseline_map.get(minute_index)
            
            if not baseline_vol or baseline_vol == 0:
                return False
            
            rvol6 = avg_vol / baseline_vol
            
            if rvol6 < 1.5:
                LOGGER.debug("top5.filter_rvol_fail", symbol=symbol, rvol6=rvol6)
                return False
        
        # 通过所有过滤
        return True
```

```python
# apps/signal_svc/engine.py
class SignalEngine:
    def process_bar(self, event: BarsClosed) -> List[SignalInstruction]:
        """
        处理单个K线闭合事件，评估所有信号逻辑
        
        返回：生成的信号列表（可能为空）
        """
        symbol = event.symbol
        ts_end = event.ts_end
        et_time = ts_end.astimezone(EASTERN)
        
        signals = []
        
        # ========== 0. 候选池检查 ==========
        if not self._is_in_candidate_pool(symbol, et_time.date()):
            return []
        
        # ========== 1. 读取数据窗口 ==========
        # 获取最近120根K线+指标（足够评估所有逻辑）
        bars_df = self._fetch_bars_window(symbol, ts_end, window=120)
        
        if len(bars_df) < 30:
            LOGGER.warning("signal.insufficient_data", symbol=symbol, rows=len(bars_df))
            return []
        
        # ========== 2. 评估买入信号 ==========
        
        # E1：开盘追高 (09:31评估)
        if et_time.hour == 9 and et_time.minute == 31:
            sig_e1 = self._evaluate_e1_open_chase(symbol, bars_df, ts_end)
            if sig_e1:
                signals.append(sig_e1)
        
        # E2：回补买入 (09:33前或10:00-10:30)
        if (et_time.hour == 9 and et_time.minute <= 33) or \
           (et_time.hour == 10 and 0 <= et_time.minute <= 30):
            sig_e2 = self._evaluate_e2_rebound(symbol, bars_df, ts_end)
            if sig_e2:
                signals.append(sig_e2)
        
        # A2/A3/A4：午后抄底 (≥14:00)
        if et_time.hour >= 14:
            # A1 Gate前置检查
            a1_gate_passed = self._check_a1_gate(symbol, bars_df, et_time.date())
            
            if a1_gate_passed:
                sig_a2 = self._evaluate_a2_second_high(symbol, bars_df, ts_end)
                sig_a3 = self._evaluate_a3_boll_pierce(symbol, bars_df, ts_end)
                sig_a4 = self._evaluate_a4_rvol_double_peak(symbol, bars_df, ts_end)
                
                signals.extend([s for s in [sig_a2, sig_a3, sig_a4] if s])
        
        # ========== 3. 评估卖出信号 ==========
        
        # S2：早盘专属（连续两根回踩上轨）
        if et_time.hour < 12:
            sig_s2 = self._evaluate_s2_double_tap(symbol, bars_df, ts_end)
            if sig_s2:
                signals.append(sig_s2)
        
        # S1：通用（整根K在上轨外→首次回到中轨）
        sig_s1 = self._evaluate_s1_box_to_mid(symbol, bars_df, ts_end)
        if sig_s1:
            signals.append(sig_s1)
        
        # 时间清仓
        if et_time.hour == 14 and et_time.minute == 0:
            sig_time_clear = self._evaluate_time_clear(symbol, et_time.date())
            if sig_time_clear:
                signals.append(sig_time_clear)
        
        return signals
```

### 3.3 E1：开盘追高信号

```python
def _evaluate_e1_open_chase(self, symbol, df, ts_end):
    """
    E1 开盘追高 (09:31评估)
    
    条件：
    1. 09:28-09:30两根阳线且后一根收更高
    2. 或：两根K开盘价均≥BOLL中轨开盘
    
    过滤：
    1. 主规则"三选二"：AO>0且上行 / CCI14>0&CCI6>0 / OBV>EMA20
    2. VIX < 20
    3. 附加过滤（可选）：MFI/Stoch二选一
    """
    
    # 提取09:28, 09:29, 09:30三根K线
    bars_0928_0930 = df[df['ts_end'].apply(
        lambda x: x.astimezone(EASTERN).hour == 9 and x.astimezone(EASTERN).minute >= 28
    )].tail(3)
    
    if len(bars_0928_0930) < 3:
        return None
    
    bar_0929 = bars_0928_0930.iloc[-2]
    bar_0930 = bars_0928_0930.iloc[-1]
    
    # ========== 条件1：两根阳线 ==========
    two_green = (bar_0929['close'] > bar_0929['open']) and \
                (bar_0930['close'] > bar_0930['open']) and \
                (bar_0930['close'] > bar_0929['close'])
    
    # ========== 条件2：开盘价≥BOLL中轨 ==========
    # 计算BOLL(20,2)
    boll_mid = df['close'].rolling(window=20).mean()
    
    open_above_mid = (bar_0929['open'] >= boll_mid.iloc[-2]) and \
                     (bar_0930['open'] >= boll_mid.iloc[-1])
    
    if not (two_green or open_above_mid):
        return None
    
    # ========== 过滤1：主规则三选二 ==========
    latest = df.iloc[-1]
    
    # AO>0且上行
    ao_pass = latest['ao'] > 0 and (latest['ao'] > df.iloc[-2]['ao'])
    
    # CCI14>0 & CCI6>0
    cci_pass = latest['cci14'] > 0 and latest['cci6'] > 0
    
    # OBV>EMA20
    obv_pass = latest['obv'] > latest['obv_ema20']
    
    main_filter_count = sum([ao_pass, cci_pass, obv_pass])
    
    if main_filter_count < 2:
        LOGGER.debug("e1.main_filter_fail", symbol=symbol, passed=main_filter_count)
        return None
    
    # ========== 过滤2：VIX Gate ==========
    vix = self._get_latest_vix()
    if vix >= 20:
        LOGGER.info("e1.vix_gate_block", symbol=symbol, vix=vix)
        return None
    
    # ========== 过滤3：附加过滤（可选） ==========
    if self.settings.feature_mfi_stoch_filter:
        # MFI>50且斜率>0
        mfi_pass = latest['mfi14'] > 50 and \
                   (latest['mfi14'] > df.iloc[-4]['mfi14'])  # 3根斜率
        
        # Stoch_K上穿Stoch_D且K<80
        stoch_pass = (df.iloc[-2]['stoch_k'] <= df.iloc[-2]['stoch_d']) and \
                     (latest['stoch_k'] > latest['stoch_d']) and \
                     (latest['stoch_k'] < 80)
        
        if not (mfi_pass or stoch_pass):
            LOGGER.debug("e1.mfi_stoch_filter_fail", symbol=symbol)
            return None
    
    # ========== 生成信号 ==========
    return SignalInstruction(
        trace_id=f"e1-{symbol}-{ts_end.isoformat()}",
        strategy_code="core-vol",
        signal_code="SIG_OPEN_CHASE_BUY",
        symbol=symbol,
        side=SignalSide.BUY,
        ts_end=ts_end,
        generated_at=utc_now(),
        confidence=0.85,  # 开盘追高高置信度
        reason={
            'two_green': two_green,
            'open_above_mid': open_above_mid,
            'ao_pass': ao_pass,
            'cci_pass': cci_pass,
            'obv_pass': obv_pass,
            'vix': vix,
            'mfi_stoch_filter_pass': True if not self.settings.feature_mfi_stoch_filter else (mfi_pass or stoch_pass)
        },
        option_hint={
            'dte_range': (2, 7),
            'otm_steps': (2, 5),
            'delta_range': (0.35, 0.45)  # 可选
        },
        risk_hint={
            'size': '1R',
            'max_total': '2R',
            'stop_pct': -0.08
        },
        ttl_seconds=180,
        cooldown_seconds=600
    )
```

### 3.4 E2：回补买入信号

```python
def _evaluate_e2_rebound(self, symbol, df, ts_end):
    """
    E2 回补买入
    
    前置：盘前两根大阴线
    - 大阴判定：价<$100时跌速≥1%/min，价≥$100时≥0.5%/min，且实体≥1×ATR14
    
    触发A：09:33前，RSI6上穿30
    触发B：10:00-10:30，第二个更低低点后轻微反弹（≤0.5×ATR14）
    
    过滤：RVOL(6)≥2 / OBV上穿EMA20 / AO由负转正，任选二
    """
    et_time = ts_end.astimezone(EASTERN)
    
    # ========== 前置：检测盘前大阴线 ==========
    premarket_bars = df[
        (df['ts_end'].apply(lambda x: x.astimezone(EASTERN).hour == 9)) &
        (df['ts_end'].apply(lambda x: x.astimezone(EASTERN).minute >= 28))
    ]
    
    if len(premarket_bars) < 2:
        return None
    
    # 判断最近两根是否都是大阴线
    big_red_count = 0
    for idx in [-2, -1]:
        bar = premarket_bars.iloc[idx]
        
        # 实体大小
        body = abs(bar['close'] - bar['open'])
        atr14 = bar['atr14']
        
        # 跌速
        price_change_pct = (bar['close'] - bar['open']) / bar['open']
        decline_rate = abs(price_change_pct)  # 每分钟
        
        # 判断标准
        price_threshold = 100
        required_decline = 0.01 if bar['close'] < price_threshold else 0.005
        
        is_big_red = (body >= atr14) and (decline_rate >= required_decline) and (bar['close'] < bar['open'])
        
        if is_big_red:
            big_red_count += 1
    
    if big_red_count < 2:
        return None
    
    # ========== 触发A：RSI6上穿30 ==========
    if et_time.hour == 9 and et_time.minute <= 33:
        latest = df.iloc[-1]
        prev = df.iloc[-2]
        
        rsi6_cross_30 = (prev['rsi6'] < 30) and (latest['rsi6'] >= 30)
        
        if not rsi6_cross_30:
            return None
        
        trigger_type = 'A'
    
    # ========== 触发B：第二个更低低点+轻微反弹 ==========
    elif et_time.hour == 10 and 0 <= et_time.minute <= 30:
        # 找出最近30分钟的所有局部低点
        recent_30min = df.tail(30)
        lows = recent_30min['low'].values
        
        # 简化：判断当前是否比前一个低点更低
        if len(lows) < 2:
            return None
        
        second_lower_low = lows[-1] < lows[-2]
        
        if not second_lower_low:
            return None
        
        # 轻微反弹：最近低点→当前高点幅度≤0.5×ATR14
        lowest_recent = min(lows[-5:])
        current_high = df.iloc[-1]['high']
        rebound_range = current_high - lowest_recent
        atr14 = df.iloc[-1]['atr14']
        
        is_light_rebound = rebound_range <= (0.5 * atr14)
        
        if not is_light_rebound:
            return None
        
        trigger_type = 'B'
    
    else:
        return None
    
    # ========== 过滤：任选二 ==========
    latest = df.iloc[-1]
    prev = df.iloc[-2]
    
    # RVOL(6)≥2
    rvol_pass = latest['rvol6'] >= 2 if latest['rvol6'] else False
    
    # OBV上穿EMA20
    obv_cross = (prev['obv'] <= prev['obv_ema20']) and (latest['obv'] > latest['obv_ema20'])
    
    # AO由负转正
    ao_turn = (prev['ao'] < 0) and (latest['ao'] >= 0)
    
    filter_pass_count = sum([rvol_pass, obv_cross, ao_turn])
    
    if filter_pass_count < 2:
        LOGGER.debug("e2.filter_fail", symbol=symbol, passed=filter_pass_count)
        return None
    
    # ========== 生成信号 ==========
    return SignalInstruction(
```

```python
def _evaluate_s2_double_tap(self, symbol, df, ts_end):
    """
    S2 早盘专属卖出（连续两根回踩上轨）
    
    条件：
    1. 当前持有E1仓位
    2. 连续两根1m收盘价回踩上轨（close < upper）
    """
    # 检查是否持有E1仓位
    positions = self._get_positions(symbol)
    has_e1_position = any(p.source_signal_code == 'SIG_OPEN_CHASE_BUY' for p in positions)
    
    if not has_e1_position:
        return None
    
    # 计算BOLL上轨
    boll_mid = df['close'].rolling(window=20).mean()
    boll_std = df['close'].rolling(window=20).std()
    boll_upper = boll_mid + 2 * boll_std
    
    latest = df.iloc[-1]
    prev = df.iloc[-2]
    
    # 连续两根回踩上轨
    double_tap = (prev['close'] < boll_upper.iloc[-2]) and \
                 (latest['close'] < boll_upper.iloc[-1])
    
    if not double_tap:
        return None
    
    return SignalInstruction(
        trace_id=f"s2-{symbol}-{ts_end.isoformat()}",
        strategy_code="core-vol",
        signal_code="SIG_EXIT_UPPER_TAP_X2",
        symbol=symbol,
        side=SignalSide.SELL,
        ts_end=ts_end,
        generated_at=utc_now(),
        confidence=0.9,
        reason={'two_upper_tap': True},
        is_exit=True,
        ttl_seconds=60
    )


def _evaluate_s1_box_to_mid(self, symbol, df, ts_end):
    """
    S1 通用卖出（整根K在上轨外→首次回到中轨）
    
    条件：
    1. 之前某根K的low > upper（整根在上轨外）
    2. 当前K首次回到中轨（low <= mid <= high且close >= mid）
    """
    # 计算BOLL
    boll_mid = df['close'].rolling(window=20).mean()
    boll_std = df['close'].rolling(window=20).std()
    boll_upper = boll_mid + 2 * boll_std
    
    # 检查最近10根K是否有"整根在上轨外"
    recent_10 = df.tail(10)
    had_box_above = any(recent_10['low'] > boll_upper[recent_10.index])
    
    if not had_box_above:
        return None
    
    # 当前K是否首次回到中轨
    latest = df.iloc[-1]
    mid_val = boll_mid.iloc[-1]
    
    back_to_mid = (latest['low'] <= mid_val <= latest['high']) and \
                  (latest['close'] >= mid_val)
    
    if not back_to_mid:
        return None
    
    return SignalInstruction(
        trace_id=f"s1-{symbol}-{ts_end.isoformat()}",
        strategy_code="core-vol",
        signal_code="SIG_EXIT_BOX2MID",
        symbol=symbol,
        side=SignalSide.SELL,
        ts_end=ts_end,
        generated_at=utc_now(),
        confidence=0.85,
        reason={'box_to_mid': True},
        is_exit=True,
        ttl_seconds=60
    )
```

```python
# apps/risk_svc/service.py
def evaluate_order(
    self,
    request: RiskCheckRequest,
    exposures: List[Position],
    current_notional: Decimal,
    pending_notional: Decimal,
    utilisation: float,
    **kwargs
) -> RiskDecision:
    """
    综合评估订单是否可下
    
    返回：RiskDecision(approved, code, reasons, detail)
    """
    reasons = []
    
    # ========== 1. Kill Switch（日内熔断） ==========
    if self._state.get('kill_switch'):
        return RiskDecision(
            approved=False,
            code='BLOCK:KILL_SWITCH',
            reasons=['daily_loss_exceeded'],
            detail={'daily_loss_r': self._state.get('drawdown_r')}
        )
    
    # ========== 2. VIX Gate ==========
    vix = self._state.get('vix_last')
    vix_gate = self.limits.vix_gate  # 默认20
    
    if request.signal_code == 'SIG_OPEN_CHASE_BUY' and vix >= vix_gate:
        return RiskDecision(
            approved=False,
            code='BLOCK:VIX_GATE',
            reasons=['vix_too_high'],
            detail={'vix': vix, 'threshold': vix_gate}
        )
    
    # ========== 3. 时间窗禁开 ==========
    now_et = utc_now().astimezone(EASTERN)
    no_new_from = self.limits.no_new_from  # 12:00
    no_new_to = self.limits.no_new_to      # 14:00
    
    if no_new_from <= now_et.time() < no_new_to:
        return RiskDecision(
            approved=False,
            code='BLOCK:TIME_WINDOW',
            reasons=['no_new_12_14'],
            detail={'time': now_et.time().isoformat()}
        )
    
    # ========== 4. 逐标的封禁 ==========
    block_entry = self.block_store.get(request.symbol)
    if block_entry:
        if block_entry['ttl'] > utc_now():
            return RiskDecision(
                approved=False,
                code=f"BLOCK:{block_entry['reason']}",
                reasons=['symbol_blocked'],
                detail={
                    'reason': block_entry['reason'],
                    'until': block_entry['ttl'].isoformat()
                }
            )
    
    # ========== 5. 并发限制 ==========
    if now_et.hour == 9 and now_et.minute <= 40:
        current_symbols = len(set(p.symbol for p in exposures))
        max_concurrent = self.limits.max_concurrent_top  # 3
        
        if current_symbols >= max_concurrent and request.symbol not in [p.symbol for p in exposures]:
            return RiskDecision(
                approved=False,
                code='BLOCK:MAX_CONCURRENT',
                reasons=['too_many_symbols'],
                detail={'current': current_symbols, 'max': max_concurrent}
            )
    
    # ========== 6. 集中度与限额 ==========
    notional_cap = self.limits.notional_cap
    if (current_notional + pending_notional) > notional_cap:
        return RiskDecision(
            approved=False,
            code='BLOCK:NOTIONAL_CAP',
            reasons=['notional_exceeded'],
            detail={
                'current': float(current_notional),
                'pending': float(pending_notional),
                'cap': float(notional_cap)
            }
        )
    
    # ========== 通过所有检查 ==========
    return RiskDecision(
        approved=True,
        code='OK',
        reasons=[],
        detail={'utilisation': utilisation},
        utilisation=utilisation
    )
```

```python
# apps/exec_svc/option_selector.py
async def _select_option_contract(symbol, dte_range, otm_steps):
    """
    从IBKR获取期权链并选择最优合约
    
    流程：
    1. reqSecDefOptParams获取可用到期日
    2. 过滤DTE在2-7天的到期日
    3. 获取当前股价
    4. 计算OTM档位（+2到+5档）
    5. reqContractDetails获取合约详情
    6. 按价差最小→OI/Vol最大→距离现价最近排序
    """
    client = _require_ib_client()
    
    # ========== 1. 获取期权链参数 ==========
    contract = stock_contract(symbol)
    sec_def_params = await asyncio.to_thread(
        client.reqSecDefOptParams,
        contract.symbol,
        "",
        contract.secType,
        contract.conId
    )
    
    if not sec_def_params:
        LOGGER.warning("option_selector.no_params", symbol=symbol)
        return None
    
    # ========== 2. 过滤到期日 ==========
    today = datetime.now(EASTERN).date()
    valid_expiries = []
    
    for param in sec_def_params:
        for expiry_str in param.expirations:
            # 格式：YYYYMMDD
            expiry_date = datetime.strptime(expiry_str, '%Y%m%d').date()
            dte = (expiry_date - today).days
            
            if dte_range[0] <= dte <= dte_range[1]:
                valid_expiries.append((expiry_str, dte))
    
    if not valid_expiries:
        LOGGER.warning("option_selector.no_valid_expiry", symbol=symbol)
        return None
    
    # 优先选择DTE最短的
    valid_expiries.sort(key=lambda x: x[1])
    selected_expiry = valid_expiries[0][0]
    
    # ========== 3. 获取当前股价 ==========
    current_price = await _get_current_price(client, symbol)
    
    if not current_price:
        return None
    
    # ========== 4. 计算OTM档位 ==========
    # 获取行权价间隔（通常$2.5或$5）
    strikes = sec_def_params[0].strikes
    strike_interval = _infer_strike_interval(strikes)
    
    # OTM +2到+5档
    otm_strikes = []
    for step in range(otm_steps[0], otm_steps[1] + 1):
        strike = current_price + step * strike_interval
        
        # 找到最接近的实际行权价
        actual_strike = min(strikes, key=lambda s: abs(float(s) - strike))
        otm_strikes.append(float(actual_strike))
    
    # ========== 5. 获取合约详情 ==========
    candidates = []
    
    for strike in otm_strikes:
        option = Contract()
        option.symbol = symbol
        option.secType = 'OPT'
        option.exchange = 'SMART'
        option.currency = 'USD'
        option.lastTradeDateOrContractMonth = selected_expiry
        option.strike = strike
        option.right = 'C'  # Call
        
        # 获取合约详情
        details = await asyncio.to_thread(client.reqContractDetails, option)
        
        if not details:
            continue
        
        contract_detail = details[0]
        
        # 获取实时报价
        ticker = await asyncio.to_thread(client.reqMktData, contract_detail.contract, '', False, False)
        
        # 等待报价更新
        await asyncio.sleep(0.5)
        
        bid = ticker.bid if hasattr(ticker, 'bid') else None
        ask = ticker.ask if hasattr(ticker, 'ask') else None
        
        if not bid or not ask:
            continue
        
        spread = ask - bid
        mid = (bid + ask) / 2
        
        # 检查流动性
        oi = ticker.openInterest if hasattr(ticker, 'openInterest') else 0
        volume = ticker.volume if hasattr(ticker, 'volume') else 0
        
        # 过滤条件
        max_spread = max(0.10, mid * 0.05)
        
        if oi < 500 or volume < 100 or spread > max_spread:
            continue
        
        candidates.append({
            'contract': contract_detail.contract,
            'strike': strike,
            'expiry': selected_expiry,
            'bid': bid,
            'ask': ask,
            'mid': mid,
            'spread': spread,
            'oi': oi,
            'volume': volume,
            'distance_to_price': abs(strike - current_price)
        })
    
    if not candidates:
        LOGGER.warning("option_selector.no_candidates", symbol=symbol)
        return None
    
    # ========== 6. 排序选择 ==========
    # 优先级：价差最小 → OI/Vol最大 → 距现价最近
    candidates.sort(key=lambda x: (
        x['spread'],          # 价差最小
        -x['oi'],             # OI最大（负号表示降序）
        -x['volume'],         # Volume最大
        x['distance_to_price']  # 距现价最近
    ))
    
    best = candidates[0]
    
    LOGGER.info(
        "option_selector.selected",
        symbol=symbol,
        strike=best['strike'],
        expiry=best['expiry'],
        spread=best['spread'],
        oi=best['oi'],
        volume=best['volume']
    )
    
    return best
```

```python
def _compute_initial_price(meta: TraceMeta) -> Decimal:
    """
    根据执行模式计算初始限价
    
    三种模式：
    1. PASSIVE（被动）: mid价，15s后调整到mid+0.2*sp
    2. MARKETABLE（可成交）: min(ask, mid+0.6*sp)
    3. FORCE（强制）: ask（买）/bid（卖），10s未成跳1档
    """
    mode = meta.mode
    side = meta.side
    mid = meta.base_mid
    spread = meta.spread
    bid = meta.bid
    ask = meta.ask
    
    if mode == ExecutionMode.PASSIVE and mid is not None:
        # 被动：从mid开始
        price = mid
    
    elif mode == ExecutionMode.FORCE:
        # 强制成交：直接打到对手价
        if side == OrderSide.BUY and ask is not None:
            price = ask
        elif side == OrderSide.SELL and bid is not None:
            price = bid
        else:
            price = meta.payload.limit_price
    
    else:  # MARKETABLE
        # 可成交限价：略微aggressive
        if side == OrderSide.BUY:
            best = [meta.payload.limit_price]
            if ask is not None:
                best.append(ask)
            if mid is not None and spread is not None:
                best.append(mid + spread * Decimal('0.6'))
            price = min(best)
        else:
            best = [meta.payload.limit_price]
            if bid is not None:
                best.append(bid)
            if mid is not None and spread is not None:
                best.append(mid - spread * Decimal('0.6'))
            price = max(best)
    
    # 对齐minTick
    return _round_to_tick(price, meta.min_tick, side)
```

```python
async def _ttl_watch(order_id, trace_id):
    """
    TTL监控：30s未成交→撤单
    第一次撤单后仅一次调价重试
    """
    await asyncio.sleep(30)
    
    async with orders_lock:
        state = orders_registry.get(order_id)
        meta = trace_meta.get(trace_id)
        
        if not state or state.status != 'submitted' or not meta:
            return
        
        # 检查尝试次数
        if meta.attempts >= 2:
            # 已重试过，最终取消
            updated = state.model_copy(
                update={
                    'status': 'cancelled',
                    'updated_at': utc_now(),
                    'reason_code': 'TTL_EXPIRED'
                }
            )
            orders_registry[order_id] = updated
            _clear_tasks(order_id)
        else:
            # 第一次超时，准备重试
            updated = state.model_copy(
                update={
                    'status': 'cancelling',
                    'updated_at': utc_now(),
                    'reason_code': 'TTL_RETRY'
                }
            )
            orders_registry[order_id] = updated
            _clear_tasks(order_id)
            retry_needed = True
    
    # 撤单
    client = _require_ib_client()
    client.cancelOrder(order_id)
    
    # 重试
    if retry_needed and meta:
        await asyncio.sleep(1)
        new_state, new_order_id = await _place_attempt(meta, trace_id, retry=True)
        
        LOGGER.info(
            "order.retry.success",
            previous_order_id=order_id,
            new_order_id=new_order_id,
            trace_id=trace_id
        )
```

```python
# apps/pnl_svc/consumer.py
async def _handle_execution_fill(fill: ExecutionFill):
    """
    处理成交回报，更新持仓与盈亏
    """
    session = session_factory()
    try:
        dao = StrategyPositionDAO(session)
        
        # ========== 1. 更新持仓 ==========
        position = dao.get_position(
            strategy_code=fill.strategy_code,
            symbol=fill.symbol,
            option_right=fill.option_right
        )
        
        if not position:
            # 新建持仓
            position = StrategyPosition(
                strategy_code=fill.strategy_code,
                symbol=fill.symbol,
                option_right=fill.option_right,
                conid=fill.conid,
                strike=fill.strike,
                expiry=fill.expiry,
                open_quantity=0,
                avg_cost=Decimal('0'),
                source_signal_code=fill.signal_code,
                opened_at=fill.filled_at
            )
            session.add(position)
        
        # 计算新的持仓与成本
        if fill.side == 'BUY':
            new_qty = position.open_quantity + fill.fill_quantity
            new_cost = (position.avg_cost * position.open_quantity + 
                       fill.fill_price * fill.fill_quantity) / new_qty
        else:  # SELL
            new_qty = position.open_quantity - fill.fill_quantity
            
            # 平仓：计算realized_pnl
            if new_qty <= 0:
                realized_pnl = (fill.fill_price - position.avg_cost) * fill.fill_quantity * OPTION_MULTIPLIER
                new_cost = Decimal('0')
            else:
                # 部分平仓
                realized_pnl = (fill.fill_price - position.avg_cost) * fill.fill_quantity * OPTION_MULTIPLIER
                new_cost = position.avg_cost  # 成本不变
        
        position.open_quantity = new_qty
        position.avg_cost = new_cost
        position.updated_at = utc_now()
        
        # ========== 2. 写入交易记录 ==========
        trade_record = TradeRecord(
            trace_id=fill.trace_id,
            order_id=fill.order_id,
            strategy_code=fill.strategy_code,
            symbol=fill.symbol,
            side=fill.side,
            quantity=fill.fill_quantity,
            price=fill.fill_price,
            fees=fill.fees or Decimal('0'),
            option_right=fill.option_right,
            strike=fill.strike,
            expiry=fill.expiry,
            signal_code=fill.signal_code,
            filled_at=fill.filled_at,
            created_at=utc_now()
        )
        session.add(trade_record)
        
        # ========== 3. 更新日内PnL ==========
        if fill.side == 'SELL' and 'realized_pnl' in locals():
            pnl_record = PnLIntraday(
                trade_date=fill.filled_at.astimezone(EASTERN).date(),
                strategy_code=fill.strategy_code,
                symbol=fill.symbol,
                realized_pnl=realized_pnl,
                fees=fill.fees or Decimal('0'),
                ts=fill.filled_at
            )
            session.add(pnl_record)
        
        session.commit()
        
        LOGGER.info(
            "pnl.fill_processed",
            symbol=fill.symbol,
            side=fill.side,
            quantity=fill.fill_quantity,
            price=fill.fill_price,
            new_position=new_qty
        )
    
    finally:
        session.close()
```

```python
# libs/infra/ibkr_client.py
class IBClient(EClient):
    def connectionClosed(self):
        """连接断开回调"""
        LOGGER.error("ibkr.connection_closed")
        self._connected = False
        
        # 自动重连（最多3次）
        for attempt in range(3):
            LOGGER.info("ibkr.reconnect_attempt", attempt=attempt+1)
            try:
                time.sleep(5)
                self.connect(self._host, self._port, self._client_id)
                
                if self._connected:
                    LOGGER.info("ibkr.reconnect_success")
                    
                    # 恢复订阅
                    self._resubscribe_all()
                    break
            except Exception as exc:
                LOGGER.exception("ibkr.reconnect_failed", attempt=attempt+1, error=str(exc))
        
        if not self._connected:
            # 通知所有服务IBKR不可用
            LOGGER.critical("ibkr.reconnect_exhausted")
```

```python
async def _reconcile_positions():
    """对账流程"""
    # 从IBKR获取持仓
    ibkr_positions = ib_client.reqPositions()
    
    # 从数据库获取持仓
    session = session_factory()
    try:
        dao = StrategyPositionDAO(session)
        db_positions = dao.list_positions()
        
        # 比对
        for db_pos in db_positions:
            ibkr_pos = next((p for p in ibkr_positions if p.conid == db_pos.conid), None)
            
            if not ibkr_pos:
                LOGGER.warning("reconcile.position_missing_in_ibkr", symbol=db_pos.symbol)
            elif abs(ibkr_pos.position - db_pos.open_quantity) > 0.01:
                LOGGER.error(

                    symbol=db_pos.symbol,
                    db_qty=db_pos.open_quantity,
                    ibkr_qty=ibkr_pos.position
                )
                # 以IBKR为准修正
                db_pos.open_quantity = ibkr_pos.position
        
        session.commit()
    finally:
        session.close()
```

```python
# Redis Stream消费（带重试）
async def consume_with_retry(stream, group, consumer):
    max_retries = 3
    
    for attempt in range(max_retries):
        try:
            entries = await redis_bus.consume(
                stream=stream,
                group=group,
                consumer=consumer,
                count=10,
                block_ms=5000
            )
            
            for entry in entries:
                try:
                    # 处理消息
                    await process_entry(entry)
                    
                    # 确认消息
                    await redis_bus.ack(stream, group, entry['id'])
                
                except Exception as exc:
                    LOGGER.exception("entry.process_failed", entry_id=entry['id'], error=str(exc))
                    
                    # 不确认，稍后会被pending重新投递
                    continue
            
            break  # 成功退出重试
        
        except Exception as exc:
            LOGGER.exception("consume.failed", attempt=attempt+1, error=str(exc))
            
            if attempt < max_retries - 1:
                await asyncio.sleep(2 ** attempt)  # 指数退避
            else:
                LOGGER.critical("consume.exhausted", stream=stream)
```

## 11. 总结

### 11.1 核心设计原则

1. **事件驱动**: Redis Streams解耦服务，异步处理，高吞吐
2. **风控前置**: 双重检查（本地+风控服务），防止违规
3. **幂等性**: trace_id机制，防止重复下单
4. **可观测**: 结构化日志 + Prometheus指标 + 完整审计
5. **容错性**: 自动重连、断线恢复、对账机制

### 11.2 数据流关键路径

```
Tick数据 → K线聚合 → 指标计算 → 信号生成 → 风控检查 → 
订单执行 → 成交回报 → 持仓更新 → 盈亏计算
```

### 11.3 时效性要求

- **K线闭合**: ≤100ms（分钟边界后）
- **指标计算**: ≤200ms
- **信号生成**: ≤300ms
- **风控检查**: ≤50ms
- **订单提交**: ≤500ms（含期权链选择）
- **端到端延迟**: ≤2秒（tick→下单）
