## 1. 系统架构总览

### 1.1 核心组件

| 组件 | 文件路径 | 职责 |
|------|---------|------|
| **入口程序** | `apps/backtest/main.py` | 解析参数、初始化Universe、调度回测 |
| **Top5构建器** | `apps/backtest/pipeline/premarket.py` | 生成盘前候选池（bt_top5） |
| **回测执行器** | `apps/backtest/bt_runner.py` | 主流程控制、两种track模式 |
| **数据访问层** | `apps/backtest/dao.py` | 读取bars/indicators/option数据 |
| **信号源** | `apps/backtest/signal_source.py` | 加载或重算信号 |
| **股票数据Feed** | `apps/backtest/datafeed/timescale_equity.py` | K线+指标数据适配BackTrader |
| **期权数据Feed** | `apps/backtest/datafeed/timescale_option.py` | 期权L1数据适配BackTrader |
| **策略** | `apps/backtest/strategy/option_signal_strategy.py` | BackTrader策略类，信号驱动交易 |
| **分析器** | `apps/backtest/analyzers/metrics_writer.py` | 绩效指标计算与写入 |
| **风控适配器** | `apps/backtest/risk_adapter.py` | 风控检查（inproc/http两种模式） |

### 1.2 技术栈

- **回测引擎**: BackTrader (事件驱动回测框架)
- **数据源**: PostgreSQL (TimescaleDB扩展)
- **信号生成**: apps/signal_svc/engine.py (复用实盘引擎)
- **风控**: 复用实盘risk_svc逻辑
- **指标计算**: ta-lib, pandas-ta

### 1.3 两种Track模式

```
┌─────────────────────────────────────────────────────────────────┐
│  Track Option (默认)                                             │
│  ├─ 使用BackTrader引擎                                           │
│  ├─ 模拟期权交易（bid/ask/spread撮合）                          │
│  ├─ 记录完整Trade明细（open_ts, close_ts, pnl, mfe, mae）      │
│  └─ 输出：bt_trades, bt_signals, bt_metrics_*                   │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  Track Equity (简化模式)                                         │
│  ├─ 不使用BackTrader，直接遍历信号                              │
│  ├─ 计算固定时间窗口收益（5/15/30/60分钟）                      │
│  ├─ 计算TFE收益（entry→first-exit）                             │
│  └─ 输出：bt_signals, bt_metrics_total (RET_SIG_*, COUNT_*)    │
└─────────────────────────────────────────────────────────────────┘
```

### 1.4 数据流向

```
Universe解析 → Top5构建 → 遍历Symbol → 
数据加载(bars+indicators+option) → 信号生成/加载 → 
风控检查 → BackTrader回测 → 成交模拟 → 
绩效计算 → 结果写入DB
```

## 2. 回测启动与初始化

### 2.1 命令行调用

```bash
python -m apps.backtest.main \
  --start 2025-10-01T09:30:00-04:00 \
  --end 2025-10-08T16:00:00-04:00 \
  --universe ref_market_cap:GLOBAL \
  --signal-mode recompute \
  --risk-mode inproc \
  --track option
```

**参数说明**:

| 参数 | 必填 | 说明 |
|------|-----|------|
| `--start` | ✅ | 回测开始时间（ISO8601+时区） |

```python
# apps/backtest/main.py
def main(argv: Iterable[str] | None = None) -> int:
    # ========== 1. 解析参数 ==========
    args = parse_args(argv)
    settings = get_settings()
    configure_logging(settings)
    
    # 生成batch_id（如bt-20251001-20251008-e17c6f）
    batch_id = _derive_batch_id(args)
    
    # 时区转换到美东
    start_et, end_et = _date_range_bounds(args.start, args.end)
    
    LOGGER.info(
        "backtest.start",
        batch=batch_id,
        start=args.start.isoformat(),
        end=args.end.isoformat(),
        signal_mode=args.signal_mode,
        risk_mode=args.risk_mode,
        universe=args.universe or "ref_market_cap:GLOBAL",
        track=args.track
    )
    
    # ========== 2. 初始化数据库连接 ==========
    engine = create_engine(settings.database_url)
    SessionLocal = sessionmaker(bind=engine)
    
    with SessionLocal() as session:
        dao = BacktestDAO(
            session,
            option_bar_table=settings.option_bar_table,
            option_chain_table=settings.option_chain_table
        )
        
        # ========== 3. 获取交易日历 ==========
        trade_dates = dao.fetch_trade_dates_between(
            start_date=start_et.date(),
            end_date=end_et.date()
        )
        
        if not trade_dates:
            raise SystemExit("No trading dates found in the requested window")
        
        LOGGER.info("backtest.trade_dates", count=len(trade_dates), dates=trade_dates)
        
        # ========== 4. 解析Universe ==========
        resolver = UniverseResolver(session)
        universe = resolver.resolve(args.universe)
        universe_code = universe.code
        
        # 如果手动指定symbols，覆盖Universe
        if args.symbols:
            universe_symbols = _deduplicate(args.symbols)
            universe_code = f"{universe_code}|manual"
        else:
            universe_symbols = universe.symbols
        
        if not universe_symbols:
            raise SystemExit("Universe resolved to zero symbols")
        
        LOGGER.info("backtest.universe_resolved", 
                   code=universe_code, 
                   count=len(universe_symbols))
        
        # ========== 5. 构建盘前Top5 ==========
        builder = PremarketTop5Builder(
            session,
            preearn_days_min=settings.preearn_days_min,
            preearn_days_max=settings.preearn_days_max,
            preearn_atr_pct_max=settings.preearn_atr_pct_max
        )
        
        observed_symbols = []
        observed_set = set()
        
        try:
            for trade_date in trade_dates:
                # 为每个交易日生成Top5候选
                rows = builder.build_for_date(
                    batch_id=batch_id,
                    trade_date=trade_date,
                    symbols=universe_symbols,
                    universe_code=universe_code
                )
                
                for row in rows:
                    symbol = str(row["symbol"]).upper()
                    if symbol not in observed_set:
                        observed_set.add(symbol)
                        observed_symbols.append(symbol)
                
                LOGGER.info(
                    "backtest.top5_cached",
                    trade_date=trade_date.isoformat(),
                    count=len(rows)
                )
            
            session.commit()
        
        except Exception:
            session.rollback()
            raise
    
    # ========== 6. 合并symbols ==========
    # 优先级：手动指定 > Top5观测到的
    requested_symbols = _deduplicate(args.symbols or [])
    
    if requested_symbols:
        final_symbols = requested_symbols[:]
        seen = set(final_symbols)
        for symbol in observed_symbols:
            if symbol not in seen:
                final_symbols.append(symbol)
                seen.add(symbol)
    else:
        final_symbols = observed_symbols[:]
    
    if not final_symbols:
        LOGGER.warning("backtest.no_symbols", reason="top5_empty", batch=batch_id)
        return 0
    
    LOGGER.info(
        "backtest.symbols_resolved",
        batch=batch_id,
        symbols=final_symbols,
        count=len(final_symbols)
    )
    
    # ========== 7. 创建Top5 Source ==========
    # 用于信号引擎查询盘前Top5
    top5_source = BacktestTop5Source(batch_id=batch_id)
    
    # ========== 8. 遍历每个Symbol执行回测 ==========
    run_ids = []
    
    for symbol in final_symbols:
        run_id = run_backtest(
            symbol=symbol,
            start=args.start,
            end=args.end,
            signal_mode=args.signal_mode,
            risk_mode=args.risk_mode,
            track=args.track,
            top5_source=top5_source,
            batch_id=batch_id,
            universe_code=universe_code,
            trade_dates=trade_dates
        )
        
        run_ids.append(run_id)
        LOGGER.info("backtest.completed", symbol=symbol, run_id=run_id, batch=batch_id)
    
    LOGGER.info("backtest.all_completed", run_ids=run_ids, batch=batch_id)
    return 0
```

### 2.3 Universe解析

```python
# apps/backtest/universe.py
class UniverseResolver:
    """
    解析Universe定义，返回股票列表
    
    支持的格式：
    1. ref_market_cap:GLOBAL - 从ref_market_cap_snapshot筛选全球市值标的
    2. ref_market_cap:US_LARGE_CAP - 美国大盘股（市值≥$100B）
    3. file:config/stock_universe.txt - 从文件读取
    4. manual:AAPL,TSLA,NVDA - 直接指定
    """
    
    def resolve(self, spec: str | None) -> Universe:
        spec = spec or "ref_market_cap:GLOBAL"
        
        if spec.startswith("ref_market_cap:"):
            # 从市值表筛选
            filter_name = spec.split(":", 1)[1]
            return self._resolve_marketcap(filter_name)
        
        elif spec.startswith("file:"):
            # 从文件读取
            file_path = spec.split(":", 1)[1]
            return self._resolve_file(file_path)
        
        elif spec.startswith("manual:"):
            # 直接指定
            symbols_str = spec.split(":", 1)[1]
            symbols = [s.strip().upper() for s in symbols_str.split(",") if s.strip()]
            return Universe(code=f"manual:{len(symbols)}", symbols=symbols)
        
        else:
            raise ValueError(f"Unsupported universe spec: {spec}")
    
    
    def _resolve_marketcap(self, filter_name: str) -> Universe:
        """
        从ref_market_cap_snapshot表筛选
        
        过滤规则：
        - GLOBAL: 市值≥$20B
        - US_LARGE_CAP: 市值≥$100B
        - US_MID_CAP: $20B ≤ 市值 < $100B
        """
        sql = """
            SELECT DISTINCT symbol
            FROM ref_market_cap_snapshot
            WHERE snapshot_date = (SELECT MAX(snapshot_date) FROM ref_market_cap_snapshot)
              AND market_cap >= :min_cap
        """
        
        if filter_name == "GLOBAL":
            min_cap = 20_000_000_000  # $20B
        elif filter_name == "US_LARGE_CAP":
            min_cap = 100_000_000_000  # $100B
        elif filter_name == "US_MID_CAP":
            min_cap = 20_000_000_000
            sql += " AND market_cap < 100000000000"
        else:
            min_cap = 20_000_000_000
        
        rows = self.session.execute(text(sql), {"min_cap": min_cap}).fetchall()
        symbols = [row[0].upper() for row in rows]
        
        return Universe(code=f"ref_market_cap:{filter_name}", symbols=symbols)
```

## 3. 盘前Top5生成 (PremarketTop5Builder)

> **目标**: 为每个交易日生成盘前候选池，写入`bt_top5`表  
> **触发时机**: 回测启动时，遍历所有trade_dates批量生成

### 3.1 核心逻辑

```python
# apps/backtest/pipeline/premarket.py
class PremarketTop5Builder:
    def __init__(
        self, 
        session: Session,
        preearn_days_min: int = 3,
        preearn_days_max: int = 5,
        preearn_atr_pct_max: Decimal = Decimal("0.02")
    ):
        self.session = session
        self.preearn_days_min = preearn_days_min
        self.preearn_days_max = preearn_days_max
        self.preearn_atr_pct_max = preearn_atr_pct_max
    
    
    def build_for_date(
        self,
        *,
        batch_id: str,
        trade_date: date,
        symbols: List[str],
        universe_code: str
    ) -> List[Dict]:
        """
        为单个交易日生成Top5
        
        流程：
        1. 拉取盘前K线（09:25-09:30）
        2. 计算盘前涨幅 = (price_0925 - prev_close) / prev_close
        3. 过滤：市值、M60、财报前限制
        4. 排序取Top5
        5. 写入bt_top5表
        """
        
        # ========== 1. 获取前一交易日收盘价 ==========
        prev_date = self._get_prev_trading_day(trade_date)
        prev_closes = self._fetch_prev_closes(symbols, prev_date)
        
        # ========== 2. 拉取盘前09:25价格 ==========
        snapshot_time = datetime(
            trade_date.year, trade_date.month, trade_date.day,
            9, 25, 0,
            tzinfo=EASTERN
        )
        
        prices_0925 = self._fetch_prices_at_time(symbols, snapshot_time)
        
        # ========== 3. 计算盘前涨幅 ==========
        candidates = []
        
        for symbol in symbols:
            prev_close = prev_closes.get(symbol)
            price_0925 = prices_0925.get(symbol)
            
            if not prev_close or not price_0925:
                continue
            
            # 涨幅计算
            premarket_gain_pct = (price_0925 - prev_close) / prev_close * 100
            
            candidates.append({
                'symbol': symbol,
                'price_0925': price_0925,
                'prev_close': prev_close,
                'premarket_gain_pct': premarket_gain_pct
            })
        
        # ========== 4. 过滤候选 ==========
        filtered = []
        
        for candidate in candidates:
            symbol = candidate['symbol']
            
            # 过滤1：市值
            if not self._check_marketcap(symbol, min_cap=100_000_000_000):  # $100B
                LOGGER.debug("top5.filter_marketcap", symbol=symbol)
                continue
            
            # 过滤2：M60趋势
            if not self._check_m60_trend(symbol, trade_date):
                LOGGER.debug("top5.filter_m60", symbol=symbol)
                continue
            
            # 过滤3：财报前限制
            if not self._check_earnings_window(symbol, trade_date):
                LOGGER.debug("top5.filter_earnings", symbol=symbol)
                continue
            
            filtered.append(candidate)
        
        # ========== 5. 排序取Top5 ==========
        filtered.sort(key=lambda x: x['premarket_gain_pct'], reverse=True)
        top5 = filtered[:5]
        
        # ========== 6. 写入bt_top5表 ==========
        rows = []
        
        for rank, item in enumerate(top5, start=1):
            payload = {
                'batch_id': batch_id,
                'trade_date': trade_date,
                'symbol': item['symbol'],
                'rank': rank,
                'price_0925': item['price_0925'],
                'prev_close': item['prev_close'],
                'premarket_gain_pct': item['premarket_gain_pct'],
                'universe_code': universe_code,
                'created_at': datetime.now(timezone.utc)
            }
            
            self.session.execute(text("""
                INSERT INTO bt_top5 (
                    batch_id, trade_date, symbol, rank,
                    price_0925, prev_close, premarket_gain_pct,
                    universe_code, created_at
                ) VALUES (
                    :batch_id, :trade_date, :symbol, :rank,
                    :price_0925, :prev_close, :premarket_gain_pct,
                    :universe_code, :created_at
                )
                ON CONFLICT (batch_id, trade_date, symbol) DO UPDATE SET
                    rank = EXCLUDED.rank,
                    price_0925 = EXCLUDED.price_0925,
                    premarket_gain_pct = EXCLUDED.premarket_gain_pct
            """), payload)
            
            rows.append(payload)
        
        LOGGER.info(
            "top5.built",
            trade_date=trade_date.isoformat(),
            count=len(top5),
            symbols=[x['symbol'] for x in top5]
        )
        
        return rows
    
    
    def _check_marketcap(self, symbol: str, min_cap: Decimal) -> bool:
        """检查市值是否满足阈值"""
        sql = text("""
            SELECT market_cap FROM ref_market_cap_snapshot
            WHERE symbol = :symbol
            ORDER BY snapshot_date DESC
            LIMIT 1
        """)
        
        row = self.session.execute(sql, {'symbol': symbol}).first()
        
        if not row:
            return False
        
        market_cap = Decimal(str(row[0]))
        return market_cap >= min_cap
    
    
    def _check_m60_trend(self, symbol: str, trade_date: date) -> bool:
        """
        检查M60趋势：Close > SMA60 且 斜率 > 0
        """
        sql = text("""
            SELECT close FROM bars_daily
            WHERE symbol = :symbol
              AND trade_date <= :trade_date
            ORDER BY trade_date DESC
            LIMIT 60
        """)
        
        rows = self.session.execute(sql, {
            'symbol': symbol,
            'trade_date': trade_date
        }).fetchall()
        
        if len(rows) < 60:
            return False
        
        closes = [Decimal(str(row[0])) for row in rows]
        closes.reverse()  # 倒序变正序
        
        # 计算SMA60
        sma60 = sum(closes) / 60
        latest_close = closes[-1]
        
        # 计算斜率（最近5日）
        if len(closes) >= 65:
            sma60_5d_ago = sum(closes[-65:-5]) / 60
            slope = (sma60 - sma60_5d_ago) / 5
        else:
            slope = Decimal("0")
        
        # 判断：收盘价>SMA60 且 斜率>0
        return latest_close > sma60 and slope > 0
    
    
    def _check_earnings_window(self, symbol: str, trade_date: date) -> bool:
        """
        财报前限制：
        若在财报前3-5天内，必须满足M60上行 或 ATR%<2%（横盘）
        """
        # 查询最近的财报日期
        sql = text("""
            SELECT earnings_date FROM earnings_calendar
            WHERE symbol = :symbol
              AND earnings_date > :trade_date
            ORDER BY earnings_date ASC
            LIMIT 1
        """)
        
        row = self.session.execute(sql, {
            'symbol': symbol,
            'trade_date': trade_date
        }).first()
        
        if not row:
            # 没有财报记录，通过
            return True
        
        earnings_date = row[0]
        days_to_earnings = (earnings_date - trade_date).days
        
        # 不在财报前窗口，通过
        if days_to_earnings < self.preearn_days_min or \
           days_to_earnings > self.preearn_days_max:
            return True
        
        # 在财报前窗口：检查M60或ATR%
        m60_pass = self._check_m60_trend(symbol, trade_date)
        
        # 检查ATR%
        atr_pct = self._get_atr_pct(symbol, trade_date)
        atr_pass = atr_pct < self.preearn_atr_pct_max if atr_pct else False
        
        # 至少满足一个
        return m60_pass or atr_pass
    
    
    def _get_atr_pct(self, symbol: str, trade_date: date) -> Decimal | None:
        """
        计算ATR%（14日ATR / 收盘价）
        """
        sql = text("""
            SELECT atr_pct FROM v_daily_atr_pct
            WHERE symbol = :symbol
              AND trade_date = :trade_date
        """)
        
        row = self.session.execute(sql, {
            'symbol': symbol,
            'trade_date': trade_date
        }).first()
        
        return Decimal(str(row[0])) if row else None
```

### 4.1 股票K线+指标获取

```python
# apps/backtest/datafeed/timescale_equity.py
class TimescaleEquityData:
    @classmethod
    def from_timescale(
        cls,
        *,
        session: Session,
        dao: BacktestDAO,
        symbol: str,
        start: datetime,
        end: datetime,
        auto_fill_missing: bool = True  # 回测中默认开启
    ) -> bt.feeds.PandasData:
        """
        从TimescaleDB读取股票K线+指标，返回BackTrader Feed
        
        流程：
        1. 查询bars1m_equity + indicators_eq_1m
        2. 扫描缺口（price_gaps, indicator_gaps, prev_close_missing）
        3. 如有缺口且auto_fill=True → 从IBKR补数
        4. 转换为DataFrame，适配BackTrader
        """
        
        # ========== 1. 查询数据 ==========
        rows = dao.fetch_equity_bars(
            symbol=symbol,
            start_ts=start,
            end_ts=end
        )
        
        if not rows:
            raise RuntimeError(
                f"No equity data for {symbol} between {start} and {end}"
            )
        
        LOGGER.info(
            "equity_data.loaded",
            symbol=symbol,
            rows=len(rows),
            start=start.isoformat(),
            end=end.isoformat()
        )
        
        # 转换为DataFrame
        df = pd.DataFrame([asdict(row) for row in rows])
        df['ts_end'] = pd.to_datetime(df['ts_end'], utc=True)
        df = df.set_index('ts_end').sort_index()
        
        # ========== 2. 扫描缺口 ==========
        gap_report = _scan_equity_gaps(df, symbol)
        
        if gap_report.has_any_gap():
            LOGGER.warning(
                "equity_data.gaps_detected",
                symbol=symbol,
                price_gaps=gap_report.price_gaps,
                indicator_nulls=gap_report.indicator_nulls,
                prev_close_missing=gap_report.prev_close_missing
            )
            
            # 写入风险事件
            dao.record_risk_event(
                event_ts=datetime.now(timezone.utc),
                symbol=symbol,
                event_code='DATA_GAP_DETECTED',
                severity='WARN',
                payload={
                    'price_gaps': gap_report.price_gaps,
                    'indicator_gaps': gap_report.indicator_nulls,
                    'prev_close_gaps': gap_report.prev_close_missing
                }
            )
            
            # ========== 3. 补数（如果启用） ==========
            if auto_fill_missing:
                settings = get_settings()
                ib_client = build_ibkr_client(settings)
                
                try:
                    # 补K线缺口
                    if gap_report.price_gaps:
                        _fill_price_gaps(
                            dao=dao,
                            ib_client=ib_client,
                            symbol=symbol,
                            gaps=gap_report.price_gaps
                        )
                    
                    # 补指标缺口
                    if gap_report.indicator_nulls:
                        _fill_indicator_gaps(
                            dao=dao,
                            symbol=symbol,
                            gaps=gap_report.indicator_nulls
                        )
                    
                    # 二次校验
                    rows = dao.fetch_equity_bars(
                        symbol=symbol,
                        start_ts=start,
                        end_ts=end
                    )
                    
                    df = pd.DataFrame([asdict(row) for row in rows])
                    df['ts_end'] = pd.to_datetime(df['ts_end'], utc=True)
                    df = df.set_index('ts_end').sort_index()
                    
                    gap_report_2 = _scan_equity_gaps(df, symbol)
                    
                    if gap_report_2.has_any_gap():
                        LOGGER.error(
                            "equity_data.gaps_persist",
                            symbol=symbol,
                            gaps=gap_report_2
                        )
                        
                        dao.record_risk_event(
                            event_ts=datetime.now(timezone.utc),
                            symbol=symbol,
                            event_code='DATA_GAP_PERSIST',
                            severity='ERROR',
                            payload={'gaps': asdict(gap_report_2)}
                        )
                    else:
                        LOGGER.info("equity_data.gaps_filled", symbol=symbol)
                        
                        dao.record_risk_event(
                            event_ts=datetime.now(timezone.utc),
                            symbol=symbol,
                            event_code='DATA_GAP_FILLED',
                            severity='INFO',
                            payload={}
                        )
                
                finally:
                    ib_client.disconnect_and_stop()
        
        # ========== 4. 转换为BackTrader Feed ==========
        # 重命名列以符合BackTrader要求
        df = df.rename(columns={
            'open': 'open',
            'high': 'high',
            'low': 'low',
            'close': 'close',
            'volume': 'volume'
        })
        
        # 添加openinterest列（BackTrader要求）
        df['openinterest'] = 0
        
        # 确保所有必需列存在
        required_cols = ['open', 'high', 'low', 'close', 'volume', 'openinterest']
        for col in required_cols:
            if col not in df.columns:
                raise RuntimeError(f"Missing required column: {col}")
        
        # 创建BackTrader Feed
        feed = bt.feeds.PandasData(
            dataname=df,
            datetime=None,  # 使用index作为时间
            open='open',
            high='high',
            low='low',
            close='close',
            volume='volume',
            openinterest='openinterest'
        )
        
        return feed


def _scan_equity_gaps(df: pd.DataFrame, symbol: str) -> GapReport:
    """
    扫描三类缺口：
    1. price_gaps: K线时间不连续（相邻两根>1分钟）
    2. indicator_nulls: 指标为NULL的时间点
    3. prev_close_missing: 缺少prev_close的时间点
    """
    price_gaps = []
    indicator_nulls = []
    prev_close_missing = []
    
    # 检查时间连续性
    timestamps = df.index.tolist()
    for i in range(1, len(timestamps)):
        gap_seconds = (timestamps[i] - timestamps[i-1]).total_seconds()
        
        if gap_seconds > 60:
            price_gaps.append({
                'from': timestamps[i-1].isoformat(),
                'to': timestamps[i].isoformat(),
                'gap_minutes': int(gap_seconds / 60)
            })
    
    # 检查指标NULL
    indicator_cols = ['rsi6', 'atr14', 'ao', 'cci14', 'obv', 'boll_mid']
    
    for col in indicator_cols:
        if col in df.columns:
            null_mask = df[col].isnull()
            null_timestamps = df[null_mask].index.tolist()
            
            if null_timestamps:
                indicator_nulls.append({
                    'column': col,
                    'count': len(null_timestamps),
                    'timestamps': [ts.isoformat() for ts in null_timestamps[:5]]  # 只记录前5个
                })
    
    # 检查prev_close
    # TODO: 实现prev_close检查逻辑
    
    return GapReport(
        symbol=symbol,
        price_gaps=price_gaps,
        indicator_nulls=indicator_nulls,
        prev_close_missing=prev_close_missing
    )
```

```python
def _recompute_signals(
    *,
    session_factory,
    dao: BacktestDAO,
    symbols: List[str],
    start: datetime,
    end: datetime,
    top5_source: Top5Source | None
) -> List[SignalInstruction]:

    1. 读取bars+indicators数据
    2. 逐分钟推进时钟
    3. 调用SignalEngine.process_bar()
    4. 收集生成的信号
    """

    # 初始化信号引擎

        session_factory=session_factory,

        # 读取K线+指标
        rows = dao.fetch_equity_bars(
            symbol=symbol,

                session=_determine_session(ts_end),

                    ts_end=ts_end.isoformat(),
                    count=len(signals),

                )

            "recompute_signals.complete",
            symbol=symbol,
            total_signals=len([s for s in all_signals if s.symbol == symbol])

    LOGGER.info(
        "recompute_signals.all_complete",
        total_signals=len(all_signals),
        symbols=symbols
    )
    
    return all_signals

def _determine_session(ts_end: pd.Timestamp) -> str:
    """判断交易时段"""
    et_time = ts_end.astimezone(EASTERN).time()
    
    if time(4, 0) <= et_time < time(9, 30):
        return 'PMO'  # Pre-Market Open
    elif time(9, 30) <= et_time < time(16, 0):
        return 'RTH'  # Regular Trading Hours
    else:
        return 'AMO'  # After-Market Open


def _parse_side(signal_code: str) -> SignalSide:
    """从signal_code推断side"""
    if 'BUY' in signal_code or 'BOTTOM' in signal_code or 'CHASE' in signal_code:
        return SignalSide.BUY
    elif 'SELL' in signal_code or 'EXIT' in signal_code or 'CLEAR' in signal_code:
        return SignalSide.SELL
    else:
        return SignalSide.BUY
```

```python
def _auto_select_contracts(
    *,
    dao: BacktestDAO,
    symbol: str,
    trade_date: date
) -> Dict[str, ContractSelection]:
    """
    自动选择期权合约
    
    流程：
    1. 查询option_chain_snapshot表
    2. 过滤DTE 2-7天
    3. 过滤OTM +2~+5档
    4. 流动性过滤：OI≥500, Vol≥100, 价差≤max($0.10, 5%*mid)
    5. 排序：价差最小 → OI/Vol最大 → 距现价最近
    6. 返回CALL和PUT各一个
    """
    contracts = {}
    
    for option_right in ('CALL', 'PUT'):
        # 查询候选合约
        candidates = dao.fetch_option_candidates(
            trade_date=trade_date,
            underlying_symbol=symbol,
            option_right=option_right,
            dte_min=2,
            dte_max=7
        )
        
        if not candidates:
            LOGGER.warning(
                "option_selector.no_candidates",
                symbol=symbol,
                right=option_right,
                trade_date=trade_date
            )
            continue
        
        # 过滤流动性
        filtered = []
        
        for candidate in candidates:
            bid = candidate.bid
            ask = candidate.ask
            mid = candidate.mid
            oi = candidate.open_interest or 0
            vol = candidate.volume or 0
            
            if not bid or not ask or not mid:
                continue
            
            spread = ask - bid
            max_spread = max(Decimal("0.10"), mid * Decimal("0.05"))
            
            # 流动性检查
            if oi < 500 or vol < 100 or spread > max_spread:
                continue
            
            filtered.append(candidate)
        
        if not filtered:
            LOGGER.warning(
                "option_selector.all_filtered",
                symbol=symbol,
                right=option_right
            )
            continue
        
        # 排序：价差最小 → OI最大 → Vol最大
        filtered.sort(key=lambda c: (
            c.ask - c.bid,           # 价差最小
            -(c.open_interest or 0), # OI最大
            -(c.volume or 0)         # Vol最大
        ))
        
        best = filtered[0]
        
        # 转换为ContractSelection
        expiry = best.expiry
        if not isinstance(expiry, datetime):
            expiry = datetime.combine(expiry, datetime.min.time(), tzinfo=timezone.utc)
        
        selection = ContractSelection(
            conid=best.conid,
            symbol=symbol,
            expiry=expiry,
            strike=best.strike,
            right=option_right,
            bid=best.bid,
            ask=best.ask,
            mid=best.mid,
            min_tick=best.min_tick or Decimal("0.01"),
            option_right=option_right,
            open_interest=best.open_interest or 0,
            volume=best.volume or 0,
            dte=best.dte or 0
        )
        
        contracts[option_right] = selection
        
        LOGGER.info(
            "option_selected",
            symbol=symbol,
            right=option_right,
            strike=best.strike,
            expiry=best.expiry,
            dte=best.dte,
            spread=float(best.ask - best.bid),
            oi=best.open_interest,
            vol=best.volume
        )
    
    if not contracts:
        raise RuntimeError(
            f"No suitable option contracts for {symbol} on {trade_date}"
        )
    
    return contracts
```

```python
# apps/backtest/strategy/option_signal_strategy.py
def _compute_limit_price(
    self,
    signal: SignalInstruction,
    bid: Decimal,
    ask: Decimal,
    mid: Decimal,
    spread: Decimal,
    min_tick: Decimal
) -> Decimal:
    """
    根据信号类型计算限价
    
    三种模式（与实盘完全一致）：
    1. MARKETABLE: 可成交限价 min(ask, mid+0.6*sp)
    2. PASSIVE: 被动限价 mid
    3. FORCE: 强制成交 ask/bid
    """
    
    side = signal.side
    
    # 判断执行模式
    if signal.signal_code.startswith("SIG_OPEN_CHASE"):
        # E1：可成交限价
        mode = ExecutionMode.MARKETABLE
    
    elif signal.signal_code.startswith("SIG_EXIT") or \
         signal.signal_code.startswith("SIG_TIME_CLEAR"):
        # 卖点/清仓：强制成交
        mode = ExecutionMode.FORCE
    
    else:
        # E2/A*：被动限价
        mode = ExecutionMode.PASSIVE
    
    # 计算价格
    if mode == ExecutionMode.MARKETABLE:
        if side == SignalSide.BUY:
            price = min(ask, mid + spread * Decimal("0.6"))
        else:
            price = max(bid, mid - spread * Decimal("0.6"))
    
    elif mode == ExecutionMode.FORCE:
        if side == SignalSide.BUY:
            price = ask
        else:
            price = bid
    
    else:  # PASSIVE
        price = mid
    
    # 对齐minTick
    return self._round_to_tick(price, min_tick, side)


def _round_to_tick(
    self,
    price: Decimal,
    min_tick: Decimal,
    side: SignalSide
) -> Decimal:
    """
    对齐最小价格跳动
    
    买入：向上取整
    卖出：向下取整
    """
    if min_tick <= 0:
        return price
    
    ticks = price / min_tick
    
    if side == SignalSide.BUY:
        ticks = ticks.quantize(Decimal("1"), rounding=ROUND_UP)
    else:
        ticks = ticks.quantize(Decimal("1"), rounding=ROUND_DOWN)
    
    return ticks * min_tick
```

```python
        LOGGER.warning(
            "order.liquidity_block",
            symbol=signal.symbol,
            spread=float(spread),
            max_spread=float(max_spread)
        )
        return False, None, "BLOCK:LIQUIDITY"
    
    # ========== 2. 撮合规则 ==========
    side = signal.side
    
    if side == SignalSide.BUY:
        # 买入：limit >= ask 立即成交
        if limit_price >= ask:
            fill_price = ask
            return True, fill_price, None
        
        # limit在mid和ask之间，且接近ask（容忍0.1*spread）
        elif mid < limit_price < ask and limit_price >= ask - Decimal("0.1") * spread:
            fill_price = limit_price  # 近似Adaptive成交
            return True, fill_price, None
        
        else:
            # 未达到成交条件
            return False, None, "NO_FILL"
    
    else:  # SELL
        # 卖出：limit <= bid 立即成交
        if limit_price <= bid:
            fill_price = bid
            return True, fill_price, None
        
        # limit在bid和mid之间，且接近bid
        elif bid < limit_price < mid and limit_price <= bid + Decimal("0.1") * spread:
            fill_price = limit_price
            return True, fill_price, None
        
        else:
            return False, None, "NO_FILL"


def _execute_signal(self, signal: SignalInstruction):
    """
    执行单个信号（BackTrader Strategy中）
    """
    
    # ========== 1. 获取期权合约 ==========
    contract = self.option_selector(signal, self.data.datetime.datetime())
    
    if not contract:
        LOGGER.warning("signal.no_contract", signal=signal.signal_code, symbol=signal.symbol)
        
        self.dao.record_signal({
            'run_id': self.run_id,
            'ts_end': signal.ts_end,
            'symbol': signal.symbol,
            'signal_code': signal.signal_code,
            'accepted': False,
            'reason': json.dumps({'code': 'NO_CONTRACT'})
        })
        
        return
    
    # ========== 2. 获取期权Feed ==========
    option_feed = self.option_feeds.get((signal.symbol.upper(), contract.option_right.upper()))
    
    if not option_feed:
        LOGGER.error("signal.no_option_feed", symbol=signal.symbol, right=contract.option_right)
        return
    
    # ========== 3. 风控预检 ==========
    risk_ok, risk_code, risk_message = self.risk_prechecker(signal, contract)
    
    if not risk_ok:
        LOGGER.info(
            "signal.risk_block",
            symbol=signal.symbol,
            signal_code=signal.signal_code,
            risk_code=risk_code
        )
        
        self.dao.record_signal({
            'run_id': self.run_id,
            'ts_end': signal.ts_end,
            'symbol': signal.symbol,
            'signal_code': signal.signal_code,
            'accepted': False,
            'reason': json.dumps({'code': risk_code, 'detail': risk_message})
        })
        
        return
    
    # ========== 4. 计算限价 ==========
    bid = Decimal(str(option_feed.bid[0]))
    ask = Decimal(str(option_feed.ask[0]))
    mid = Decimal(str(option_feed.close[0]))
    spread = ask - bid
    min_tick = contract.min_tick
    
    limit_price = self._compute_limit_price(
        signal=signal,
        bid=bid,
        ask=ask,
        mid=mid,
        spread=spread,
        min_tick=min_tick
    )
    
    # ========== 5. 尝试撮合 ==========
    filled, fill_price, fail_reason = self._try_execute_order(
        signal=signal,
        option_feed=option_feed,
        limit_price=limit_price
    )
    
    if not filled:
        LOGGER.debug(
            "signal.no_fill",
            symbol=signal.symbol,
            signal_code=signal.signal_code,
            reason=fail_reason
        )
        
        self.dao.record_signal({
            'run_id': self.run_id,
            'ts_end': signal.ts_end,
            'symbol': signal.symbol,
            'signal_code': signal.signal_code,
            'accepted': False,
            'reason': json.dumps({
                'code': fail_reason,
                'limit': float(limit_price),
                'bid': float(bid),
                'ask': float(ask)
            })
        })
        
        return
    
    # ========== 6. 下单到BackTrader ==========
    quantity = 1  # 简化：固定1手
    
    if signal.side == SignalSide.BUY:
        order = self.buy(
            data=option_feed,
            size=quantity,
            price=float(fill_price),
            exectype=bt.Order.Limit
        )
    else:
        order = self.sell(
            data=option_feed,
            size=quantity,
            price=float(fill_price),
            exectype=bt.Order.Limit
        )
    
    # 记录订单元数据
    order.signal = signal
    order.contract = contract
    order.fill_price_expected = fill_price
    
    # 记录信号（accepted=True）
    self.dao.record_signal({
        'run_id': self.run_id,
        'ts_end': signal.ts_end,
        'symbol': signal.symbol,
        'signal_code': signal.signal_code,
        'accepted': True,
        'reason': json.dumps({
            'code': 'OK',
            'limit': float(limit_price),
            'fill': float(fill_price),
            'bid': float(bid),
            'ask': float(ask),
            'spread': float(spread)
        })
    })
    
    LOGGER.info(
        "signal.executed",
        symbol=signal.symbol,
        signal_code=signal.signal_code,
        side=signal.side.value,
        fill_price=float(fill_price),
        quantity=quantity
    )
```

```python
# apps/backtest/strategy/option_signal_strategy.py
class OptionSignalStrategy(bt.Strategy):
    """
    期权信号驱动策略（BackTrader）
    
    职责：
    1. 接收外部信号（load_signals提供）
    2. 调用风控检查
    3. 下单到BackTrader引擎
    4. 处理成交回调
    5. 记录Trade明细
    """
    
    params = (
        ('dao', None),
        ('signals', []),
        ('run_id', None),
        ('option_selector', None),
        ('risk_ctx', None),
        ('risk_prechecker', None),
        ('option_feeds', {}),
    )
    
    def __init__(self):
        # 按时间索引信号
        self.signals_by_time = defaultdict(list)
        
        for signal in self.params.signals:
            ts_key = signal.ts_end.replace(microsecond=0)
            self.signals_by_time[ts_key].append(signal)
        
        LOGGER.info(
            "strategy.init",
            run_id=self.params.run_id,
            total_signals=len(self.params.signals),
            unique_timestamps=len(self.signals_by_time)
        )
        
        # 持仓跟踪
        self.positions_map = {}  # {(symbol, right): Position}
        self.orders_pending = {}  # {order_id: Order}
    
    
    def next(self):
        """
        每个时间步调用（BackTrader核心方法）
        
        流程：
        1. 获取当前时间
        2. 查找该时间的信号
        3. 执行信号
        """
        # 获取当前时间
        current_dt = self.data.datetime.datetime()
        ts_key = current_dt.replace(microsecond=0)
        
        # 获取该时间的信号
        signals = self.signals_by_time.get(ts_key, [])
        
        if not signals:
            return
        
        LOGGER.debug(
            "strategy.next",
            ts=current_dt.isoformat(),
            signals=len(signals)
        )
        
        # 优先处理SELL信号
        sell_signals = [s for s in signals if s.side == SignalSide.SELL]
        buy_signals = [s for s in signals if s.side == SignalSide.BUY]
        
        # 先处理卖出
        for signal in sell_signals:
            self._execute_signal(signal)
        
        # 再处理买入
        for signal in buy_signals:
            self._execute_signal(signal)
    
    
    def notify_order(self, order):
        """
        订单状态变化回调（BackTrader核心方法）
        """
        if order.status in [order.Submitted, order.Accepted]:
            # 订单已提交/已接受
            return
        
        if order.status == order.Completed:
            # 订单成交
            self._handle_order_filled(order)
        
        elif order.status in [order.Canceled, order.Margin, order.Rejected]:
            # 订单取消/拒绝
            LOGGER.warning(
                "order.failed",
                status=order.getstatusname(),
                signal=getattr(order, 'signal', None)
            )
    
    
    def notify_trade(self, trade):
        """
        交易完成回调（BackTrader核心方法）
        
        当一个完整的开仓→平仓周期完成时触发
        """
        if not trade.isclosed:
            return
        
        # 交易已关闭，计算盈亏
        self._handle_trade_closed(trade)
    
    
    def _handle_order_filled(self, order):
        """处理订单成交"""
        signal = getattr(order, 'signal', None)
        contract = getattr(order, 'contract', None)
        
        if not signal or not contract:
            LOGGER.error("order.missing_metadata", order_id=id(order))
            return
        
        # 记录成交
        fill_price = order.executed.price
        fill_size = order.executed.size
        fill_value = order.executed.value
        commission = order.executed.comm
        
        LOGGER.info(
            "order.filled",
            symbol=signal.symbol,
            signal_code=signal.signal_code,
            side=signal.side.value,
            fill_price=fill_price,
            fill_size=fill_size,
            commission=commission
        )
        
        # 更新持仓跟踪
        key = (signal.symbol.upper(), contract.option_right.upper())
        
        if signal.side == SignalSide.BUY:
            # 开仓
            self.positions_map[key] = {
                'signal': signal,
                'contract': contract,
                'open_ts': signal.ts_end,
                'open_price': Decimal(str(fill_price)),
                'quantity': abs(fill_size),
                'open_value': abs(fill_value),
                'open_commission': commission
            }
        
        else:
            # 平仓（由notify_trade处理PnL）
            if key in self.positions_map:
                pos = self.positions_map[key]
                pos['close_ts'] = signal.ts_end
                pos['close_price'] = Decimal(str(fill_price))
                pos['close_value'] = abs(fill_value)
                pos['close_commission'] = commission
    
    
    def _handle_trade_closed(self, trade):
        """处理交易关闭（完整的开→平周期）"""
        # 计算盈亏
        pnl_gross = trade.pnl
        pnl_net = trade.pnlcomm  # 扣除佣金后
        
        # 计算MFE/MAE
        mfe = 0.0  # Maximum Favorable Excursion
        mae = 0.0  # Maximum Adverse Excursion
        
        # 从持仓跟踪中获取元数据
        # TODO: 关联signal和contract信息
        
        # 写入bt_trades表
        self.params.dao.record_trade({
            'run_id': self.params.run_id,
            'symbol': '???',  # 从trade对象提取
            'signal_code': '???',
            'open_ts': trade.dtopen,
            'close_ts': trade.dtclose,
            'side': 'LONG',
            'quantity': trade.size,
            'open_price': trade.price,
            'close_price': trade.price + pnl_gross / trade.size,
            'gross_pnl': pnl_gross,
            'net_pnl': pnl_net,
            'fees': trade.commission,
            'mfe': mfe,
            'mae': mae,
            'exit_reason': 'SIGNAL'
        })
        
        LOGGER.info(
            "trade.closed",
            pnl_gross=pnl_gross,
            pnl_net=pnl_net,
            duration_minutes=(trade.dtclose - trade.dtopen).total_seconds() / 60
        )
```

```python
# apps/backtest/analyzers/metrics_writer.py
class MetricsWriter(bt.Analyzer):
    """
    BackTrader分析器：计算回测绩效指标并写入数据库
    
    输出表：
    - bt_metrics_daily: 日度指标
    - bt_metrics_total: 总体指标
    """
    
    params = (
        ('dao', None),
        ('run_id', None),
    )
    
    def __init__(self):
        self.daily_pnl = defaultdict(Decimal)  # {date: pnl}
        self.daily_trades = defaultdict(int)
        self.daily_wins = defaultdict(int)
        self.all_pnls = []
    
    
    def notify_trade(self, trade):
        """每笔交易完成时调用"""
        if not trade.isclosed:
            return
        
        trade_date = trade.dtclose.astimezone(EASTERN).date()
        pnl = Decimal(str(trade.pnlcomm))
        
        # 累计日度数据
        self.daily_pnl[trade_date] += pnl
        self.daily_trades[trade_date] += 1
        
        if pnl > 0:
            self.daily_wins[trade_date] += 1
        
        # 累计全局数据
        self.all_pnls.append(pnl)
    
    
    def stop(self):
        """
        回测结束时调用，计算并写入指标
        """
        # ========== 1. 日度指标 ==========
        daily_metrics = []
        
        for trade_date in sorted(self.daily_pnl.keys()):
            pnl = self.daily_pnl[trade_date]
            num_trades = self.daily_trades[trade_date]
            num_wins = self.daily_wins[trade_date]
            win_rate = num_wins / num_trades if num_trades > 0 else 0
            
            daily_metrics.append({
                'run_id': self.params.run_id,
                'trade_date': trade_date,
                'metric_code': 'DAILY_PNL',
                'metric_value': float(pnl)
            })
            
            daily_metrics.append({
                'run_id': self.params.run_id,
                'trade_date': trade_date,
                'metric_code': 'DAILY_TRADES',
                'metric_value': num_trades
            })
            
            daily_metrics.append({
                'run_id': self.params.run_id,
                'trade_date': trade_date,
                'metric_code': 'DAILY_WIN_RATE',
                'metric_value': win_rate
            })
        
        if daily_metrics:
            self.params.dao.record_metrics_daily(daily_metrics)
        
        # ========== 2. 总体指标 ==========
        if not self.all_pnls:
            return
        
        total_metrics = []
        
        # 总盈亏
        total_pnl = sum(self.all_pnls)
        total_metrics.append({
            'run_id': self.params.run_id,
            'metric_code': 'TOTAL_PNL',
            'metric_value': float(total_pnl)
        })
        
        # 总交易数
        total_trades = len(self.all_pnls)
        total_metrics.append({
            'run_id': self.params.run_id,
            'metric_code': 'TOTAL_TRADES',
            'metric_value': total_trades
        })
        
        # 胜率
        wins = sum(1 for pnl in self.all_pnls if pnl > 0)
        win_rate = wins / total_trades if total_trades > 0 else 0
        total_metrics.append({
            'run_id': self.params.run_id,
            'metric_code': 'WIN_RATE',
            'metric_value': win_rate
        })
        
        # 平均盈利/亏损
        winning_trades = [pnl for pnl in self.all_pnls if pnl > 0]
        losing_trades = [pnl for pnl in self.all_pnls if pnl < 0]
        
        if winning_trades:
            avg_win = sum(winning_trades) / len(winning_trades)
            total_metrics.append({
                'run_id': self.params.run_id,
                'metric_code': 'AVG_WIN',
                'metric_value': float(avg_win)
            })
        
        if losing_trades:
            avg_loss = sum(losing_trades) / len(losing_trades)
            total_metrics.append({
                'run_id': self.params.run_id,
                'metric_code': 'AVG_LOSS',
                'metric_value': float(avg_loss)
            })
        
        # Profit Factor
        if losing_trades:
            gross_profit = sum(winning_trades) if winning_trades else Decimal("0")
            gross_loss = abs(sum(losing_trades))
            profit_factor = gross_profit / gross_loss if gross_loss > 0 else 0
            
            total_metrics.append({
                'run_id': self.params.run_id,
                'metric_code': 'PROFIT_FACTOR',
                'metric_value': float(profit_factor)
            })
        
        # 最大回撤
        max_dd = self._calculate_max_drawdown(self.all_pnls)
        total_metrics.append({
            'run_id': self.params.run_id,
            'metric_code': 'MAX_DRAWDOWN',
            'metric_value': float(max_dd)
        })
        
        # Sharpe Ratio（假设无风险利率=0）
        if len(self.all_pnls) > 1:
            pnl_array = np.array([float(p) for p in self.all_pnls])
            mean_pnl = np.mean(pnl_array)
            std_pnl = np.std(pnl_array)
            
            sharpe = mean_pnl / std_pnl * np.sqrt(252) if std_pnl > 0 else 0
            
            total_metrics.append({
                'run_id': self.params.run_id,
                'metric_code': 'SHARPE_RATIO',
                'metric_value': float(sharpe)
            })
        
        # 写入数据库
        if total_metrics:
            self.params.dao.record_metrics_total(total_metrics)
        
        LOGGER.info(
            "metrics.written",
            run_id=self.params.run_id,
            total_pnl=float(total_pnl),
            win_rate=win_rate,
            total_trades=total_trades
        )
    
    
    def _calculate_max_drawdown(self, pnls: List[Decimal]) -> Decimal:
        """计算最大回撤"""
        cumulative = 0
        peak = 0
        max_dd = 0
        
        for pnl in pnls:
            cumulative += pnl
            peak = max(peak, cumulative)
            dd = peak - cumulative
            max_dd = max(max_dd, dd)
        
        return max_dd
```

### 14.1 佣金计算

```python
# apps/backtest/broker/commission_ib.py
class IBOptionCommissionInfo(bt.CommInfoBase):
    """
    Interactive Brokers期权佣金模型
    
    费率结构：
    - 基础佣金：$0.65/手
    - 最低佣金：$1.00/单
    - 交易所费用：$0.10/手（估算）
    - 清算费：$0.05/手
    - SEC费：成交金额 * 0.0000221
    """
    
    params = (
        ('commission', 0.65),      # 基础佣金
        ('mult', 100),             # 期权乘数
        ('margin', None),          # 不使用保证金
        ('commtype', bt.CommInfoBase.COMM_FIXED),  # 固定佣金
        ('stocklike', False),      # 期权类型
    )
    
    def _getcommission(self, size, price, pseudoexec):
        """
        计算单笔委托的佣金
        
        参数：
            size: 手数
            price: 成交价
            pseudoexec: 是否模拟执行
        
        返回：
            总佣金（美元）
        """
        # 基础佣金
        base_comm = abs(size) * self.p.commission
        
        # 交易所费用+清算费
        exchange_fees = abs(size) * 0.15
        
        # SEC费
        notional = abs(size) * price * self.p.mult
        sec_fee = notional * 0.0000221
        
        # 总计
        total_comm = base_comm + exchange_fees + sec_fee
        
        # 最低佣金
        total_comm = max(total_comm, 1.00)
        
        return total_comm
```

### 14.2 滑点模型

```python
# apps/backtest/broker/slippage_spread.py
@dataclass
class ExecutionPath:
    """
    执行路径：描述订单如何逐步调价
    
    用于模拟TTL=30s + 仅一次重试的真实执行逻辑
    """
    mode: ExecutionMode
    steps: List[PriceStep]
    max_attempts: int = 2


@dataclass
class PriceStep:
    """单个价格步骤"""
    delay_seconds: int
    price_offset: Decimal  # 相对于base_price的偏移
    timeout_seconds: int


def build_execution_path(mode: ExecutionMode, side: OrderSide) -> ExecutionPath:
    """
    根据执行模式构建路径
    """
    
    if mode == ExecutionMode.MARKETABLE:
        # 可成交限价：一次性，30s超时
        return ExecutionPath(
            mode=mode,
            steps=[
                PriceStep(
                    delay_seconds=0,
                    price_offset=Decimal("0.6") if side == OrderSide.BUY else Decimal("-0.6"),
                    timeout_seconds=30
                )
            ],
            max_attempts=2
        )
    
    elif mode == ExecutionMode.PASSIVE:
        # 被动限价：从mid开始，15s后调整
        return ExecutionPath(
            mode=mode,
            steps=[
                PriceStep(
                    delay_seconds=0,
                    price_offset=Decimal("0"),  # mid
                    timeout_seconds=15
                ),
                PriceStep(
                    delay_seconds=15,
                    price_offset=Decimal("0.2") if side == OrderSide.BUY else Decimal("-0.2"),
                    timeout_seconds=15
                )
            ],
            max_attempts=2
        )
    
    elif mode == ExecutionMode.FORCE:
        # 强制成交：从bid/ask开始，每10s跳1档
        return ExecutionPath(
            mode=mode,
            steps=[
                PriceStep(delay_seconds=0, price_offset=Decimal("0"), timeout_seconds=10),
                PriceStep(delay_seconds=10, price_offset=Decimal("1"), timeout_seconds=10),  # 跳1档
                PriceStep(delay_seconds=20, price_offset=Decimal("2"), timeout_seconds=10),  # 跳2档
                PriceStep(delay_seconds=30, price_offset=Decimal("3"), timeout_seconds=10),  # 跳3档
            ],
            max_attempts=1  # 强制成交不重试
        )
    
    else:
        raise ValueError(f"Unknown execution mode: {mode}")


def calculate_slippage(
    fill_price: Decimal,
    mid_at_submit: Decimal,
    side: OrderSide
) -> Decimal:
    """
    计算滑点
    
    买入：fill - mid（正数表示多付）
    卖出：mid - fill（正数表示少收）
    """
    if side == OrderSide.BUY:
        slippage = fill_price - mid_at_submit
    else:
        slippage = mid_at_submit - fill_price
    
    return slippage
```

```sql
-- 单次回测的综合报告
WITH run_info AS (
    SELECT 
        run_id,
        strategy_code,
        parameters->>'symbol' AS symbol,
        parameters->>'batch_id' AS batch_id,
        started_at,
        completed_at,
        status
    FROM bt_runs
    WHERE run_id = :run_id
),
trade_summary AS (
    SELECT 
        COUNT(*) AS total_trades,
        SUM(CASE WHEN net_pnl > 0 THEN 1 ELSE 0 END) AS winning_trades,
        SUM(CASE WHEN net_pnl < 0 THEN 1 ELSE 0 END) AS losing_trades,
        SUM(net_pnl) AS total_pnl,
        AVG(net_pnl) AS avg_pnl,
        MAX(net_pnl) AS max_win,
        MIN(net_pnl) AS max_loss,
        SUM(fees) AS total_fees
    FROM bt_trades
    WHERE run_id = :run_id
),
signal_summary AS (
    SELECT 
        signal_code,
        COUNT(*) AS total,
        SUM(CASE WHEN accepted THEN 1 ELSE 0 END) AS accepted,
        SUM(CASE WHEN NOT accepted THEN 1 ELSE 0 END) AS blocked
    FROM bt_signals
    WHERE run_id = :run_id
    GROUP BY signal_code
),
metrics AS (
    SELECT 
        metric_code,
        metric_value
    FROM bt_metrics_total
    WHERE run_id = :run_id
)
SELECT 
    r.*,
    t.*,
    json_agg(s.*) AS signal_stats,
    json_object_agg(m.metric_code, m.metric_value) AS metrics
FROM run_info r
CROSS JOIN trade_summary t
CROSS JOIN signal_summary s
CROSS JOIN metrics m
GROUP BY r.run_id, r.strategy_code, r.symbol, r.batch_id, 
         r.started_at, r.completed_at, r.status,
         t.total_trades, t.winning_trades, t.losing_trades,
         t.total_pnl, t.avg_pnl, t.max_win, t.max_loss, t.total_fees;
```

```python
        # 读取基本信息
        run_info = conn.execute(text("""
            SELECT * FROM bt_runs WHERE run_id = :run_id
        """), {'run_id': run_id}).first()
        
        # 读取交易
        trades = conn.execute(text("""
            SELECT * FROM bt_trades WHERE run_id = :run_id ORDER BY open_ts
        """), {'run_id': run_id}).fetchall()
        
        # 读取信号
        signals = conn.execute(text("""
            SELECT * FROM bt_signals WHERE run_id = :run_id ORDER BY ts_end
        """), {'run_id': run_id}).fetchall()
        
        # 读取指标
        metrics = conn.execute(text("""
            SELECT * FROM bt_metrics_total WHERE run_id = :run_id
        """), {'run_id': run_id}).fetchall()
    
    # 生成报告
    report = f"""

- **总盈亏**: ${sum(t['net_pnl'] for t in trades):.2f}
```

### 17.2 Walk-Forward分析

```python
# scripts/walk_forward_analysis.py
def walk_forward_analysis(
    symbols: List[str],
    total_period: Tuple[date, date],
    train_days: int = 60,
    test_days: int = 20
):
    """
    滚动窗口分析
    
    流程：
    1. 在训练窗口（60天）优化参数
    2. 在测试窗口（20天）验证
    3. 滚动窗口，重复上述过程
    """
    
    start_date, end_date = total_period
    current_date = start_date
    
    results = []
    
    while current_date + timedelta(days=train_days + test_days) <= end_date:
        # 训练窗口
        train_start = current_date
        train_end = current_date + timedelta(days=train_days)
        
        # 测试窗口
        test_start = train_end + timedelta(days=1)
        test_end = test_start + timedelta(days=test_days)
        
        print(f"Train: {train_start} ~ {train_end}")
        print(f"Test: {test_start} ~ {test_end}")
        
        # 在训练窗口优化参数
        best_params = optimize_params(
            symbols=symbols,
            start=train_start,
            end=train_end
        )
        
        # 在测试窗口验证
        test_metrics = backtest_with_params(
            symbols=symbols,
            start=test_start,
            end=test_end,
            params=best_params
        )
        
        results.append({
            'train_period': (train_start, train_end),
            'test_period': (test_start, test_end),
            'best_params': best_params,
            'test_sharpe': test_metrics['SHARPE_RATIO'],
            'test_pnl': test_metrics['TOTAL_PNL']
        })
        
        # 滚动窗口
        current_date += timedelta(days=test_days)
    
    # 分析稳定性
    sharpe_values = [r['test_sharpe'] for r in results]
    
    print(f"\n=== Walk-Forward Results ===")
    print(f"平均Sharpe: {np.mean(sharpe_values):.2f}")
    print(f"Sharpe标准差: {np.std(sharpe_values):.2f}")
    print(f"胜率窗口数: {sum(1 for s in sharpe_values if s > 0)} / {len(sharpe_values)}")
```

### 18.2 关键设计原则

1. **代码复用最大化**: 
   - 信号引擎100%复用实盘代码
   - 指标计算100%复用实盘代码
   - 风控逻辑可选http模式调用真实服务

2. **历史数据驱动**:
   - 依赖TimescaleDB完整数据
   - 自动检测缺口并补数
   - 支持多种数据源（bars1m_option / option_l1_snapshot）

3. **BackTrader引擎**:
   - 成熟的事件驱动回测框架
   - 自动处理订单/持仓/PnL
   - 支持自定义佣金/滑点模型

4. **双Track模式**:
   - Option: 完整模拟期权交易，记录详细Trade
   - Equity: 简化模式，快速验证信号收益率

5. **完整审计**:
   - 所有信号（accepted/blocked）记录到bt_signals
   - 所有交易记录到bt_trades
   - 阻断原因、风控事件完整可追溯

### 18.3 时效性要求

- **Top5构建**: ≤10秒/交易日
- **数据加载**: ≤5秒/symbol（无缺口时）
- **信号重算**: ≤30秒/symbol/周（~2000根K线）
- **BackTrader回测**: ≤60秒/symbol/周
- **总体**: ≤10分钟（10个symbols，1周数据）
