# 风险管理与动态调整

> 严格对齐你的原始策略与一页式手册，只保“能跑”的最小集合；不引入评分、复杂模型或多余流程。

------

## 1) 运行与依赖

- **时区**：US/Eastern（评估与定时）；数据库存 UTC。
- **频率**：1m（以 `ts_end` 表示该分钟闭合）。
- **依赖**：`signals`、`positions`、`pnl_intraday`/`pnl_daily`、`bars1m_equity`、`indicators_eq_1m`、`dim_trading_calendar`、（可选）VIX 实时/延时行情、IB 合约最小跳（仅执行层用）。

**通信**

- 订阅事件：`bars_closed`（每分钟）、`signals`（候选指令）、`execution_fills`（成交）、`risk_param_reload`（热更新）。
- 广播事件：`risk_block`（拒绝/撤单/禁开）、`risk_unblock`（解除）、`risk_alert`（阈击穿）。

**存储与监控**

- TimescaleDB 持久化；所有风险状态用 Hypertable，便于回放与审计。
- Prometheus监控。

------

## 2) 数据模型（表与关键字段）

> 仅列字段，不给 DDL。

### 2.1 配置与阈值

- **`risk_limits`**（静态/少变配置）
  - `key`（如 `stop_loss_pct`、`vix_gate`、`daily_loss_r`、`max_concurrent_top`、`no_new_from`、`no_new_to`、`iv_overnight_call_cap`）
  - `value`（字符串存储，解析为数值/时间段）
  - `scope`（`global` / `symbol_bucket` / `symbol`）
  - `effective_from`、`updated_at`、`updated_by`

### 2.2 状态与度量

- **`risk_state`**（Hypertable，1m 刷新）
  - 时间：`ts_end`
  - 组合：`equity`, `realized_pnl_day`, `unrealized_pnl`, `drawdown_r`, `used_R`（已用风险单位）
  - 头寸概览：`num_positions`, `num_symbols_top`, `gamma_est`, `theta_est`（若无 Greeks 则为空）
  - 市场态：`vix`, `regime`（`LOW`/`MID`/`HIGH`）
  - 运行态：`gate_open_chase`（bool）、`kill_switch`（bool）
- **`risk_events`**（审计与告警）
  - `ts`, `symbol`, `event_code`（如 `HARD_STOP`, `DAILY_CUTOFF`, `VIX_GATE_ON`）
  - `details_json`（触发值、阈值、参考K线、信号ID 等）
  - `action`（`BLOCK` / `FORCE_CLOSE` / `WARN`）
  - `trace_id`
- 复用：`positions`、`orders`、`fills`、`pnl_intraday`/`pnl_daily`（若未建，按最小字段新建）。

## 3) 硬栅栏（命中即阻断/强平）

> 默认值来自你的一页式手册，全部可在 `risk_limits` 热更。

1. **单笔止损**：期权 **硬止损 −8%**（`stop_loss_pct=0.08`）。

   - 实施：订阅 `bars_closed` 与 `fills`；按持仓均价计算浮亏≤−8% → `FORCE_CLOSE` 市价/保护价全平。
   - **互补止损**：若“对应正股下行 **0.5×ATR14** 的 Δ 估损”更紧，则取更紧者（需要该合约有 Δ，由执行层估算提供）。

2. **时间禁开仓**：**12:00–14:00** 禁开新仓（`no_new_from=12:00`, `no_new_to=14:00`）。

3. **清仓时点**：

   - 早盘追高仓位：**14:00 前** 必清（`cutoff_open_chase=14:00`）。
   - 隔夜持仓：次日 **12:00 前** 必清（`cutoff_overnight=12:00`）。

4. **隔夜 IV 限制（看涨）**：**IV>110% 的看涨**禁止隔夜（`iv_overnight_call_cap=1.10`）。收盘前命中 → `FORCE_CLOSE`。

5. **VIX 闸门**：当 **VIX ≥ 20**，关闭“开盘追高”信号（`vix_gate=20`）。

6. **流动性门槛**（执行前检查）：`OI≥500`、`Volume≥100`、`价差 ≤ max($0.10, 5%)`；不达标 → 拒单（`risk_block`）。

7. **并发与集中度**：开盘后 **10 分钟内** 重仓最多 **3 只**（`max_concurrent_top=3`）。

8. **日内亏损熔断**：当日净亏 **≥ daily_loss_r · R**（默认 `daily_loss_r=3`）→ `kill_switch=true`，系统“只出不入”。

9. 逐标的动态禁开（MIDFAIL）

   - **事件**：`MIDFAIL`（开盘 ≤ 15 分钟内，价格“急跌触中轨”，且**之后 10 分钟内未回中轨之上**）。
   - **动作**：记录 `risk_events(event_code='MIDFAIL')`，将该 `symbol` 加入 **Block-Until-14:00** 名单（仅禁开仓，不影响卖出/平仓）。

   

------

## 5) 运行流程（SOP）

### 开盘前（ET）

- **09:15**：重置当日风险（`used_R=0`, `kill_switch=false`），加载 `risk_limits`；
- **09:20**：拉取 VIX；设 `regime` 与 `gate_open_chase`（若 VIX≥20 则关）。

### 盘中（每 1m on `bars_closed`）

1. 刷新 `risk_state`：day PnL、drawdown_r、num_positions、vix、regime。
2. 检查硬栅栏：单笔 −8% → `FORCE_CLOSE`；12:00–14:00 禁开；14:00/次日12:00 清仓。
3. 组合集中度：10 分钟窗口内新开 ≥3 只 → 后续候选 `risk_block`，直到超时。
4. 记录 `risk_events`（审计/告警）。

### 收盘与隔夜

- **15:50–16:00**：检查所有看涨仓位 `IV>110%` → 强平。

------

## 6) 与执行/信号接口（最小顺序）

- 收到 `signals` 时：
  1. `kill_switch?` 是→ `risk_block`；
  2. 时间窗（12:00–14:00）→ `risk_block`；
  3. VIX gate 影响开盘追高？→ `risk_block`；
  4. `symbol_block_ttl`（若有）未过？→ `risk_block`；
  5. 通过→ 放行给执行层。
- 已持仓：任何时刻触发 **−8%** 或 **S1/S2 卖点** 或 **时间清仓** → 下发 `FORCE_CLOSE`。
- 错过进场的当日禁开（MISSED_ENTRY）
  - **触发**：09:31 的 `SIG_OPEN_CHASE_BUY` / `SIG_REBOUND_BUY` **TTL 到期**且**未成交**（或被风控拒绝）。
  - **动作**：记录 `risk_events(event_code='MISSED_ENTRY')`，将该 `symbol` **Block-Until-Close**（或配置为 `Until-14:00`）。

## 7) 参数清单（推荐默认）

| 键                         | 默认              | 说明                        |
| -------------------------- | ----------------- | --------------------------- |
| `stop_loss_pct`            | 0.08              | 期权硬止损 8%               |
| `no_new_from`/`no_new_to`  | 12:00 / 14:00     | 时间禁开仓窗口              |
| `cutoff_open_chase`        | 14:00             | 早盘追高仓位清仓时点        |
| `cutoff_overnight`         | 12:00             | 隔夜持仓清仓时点            |
| `iv_overnight_call_cap`    | 1.10              | IV>110% 看涨禁止隔夜        |
| `vix_gate`                 | 20                | ≥20 关闭开盘追高            |
| `daily_loss_r`             | 3                 | 当日亏损达到 3R 熔断        |
| `max_concurrent_top`       | 3                 | 开盘 10 分钟内最多重仓 3 只 |
| `symbol_block_ttl`         | 10m               | 价差过宽/异常后的禁开时长   |
| `R_per_trade_low/mid/high` | 1.0R / 0.75R / 0R | Regime 下的每单风险单位     |

> 所有参数均可在 `risk_limits` 热更新，`risk-service` 监听 `risk_param_reload` 立刻生效。
