## 八、已知问题与解决方案

### 8.1 IBKR Client ID 冲突

**问题**: 多个进程使用相同的 Client ID

**解决方案**: 
```bash
# 使用不同的 Client ID
IB_CLIENT_ID=96 python -m apps.backtest.data_prep.ingest_equity_1m_ibkr ...
```

### 8.2 端口占用

**问题**: 端口9091已被占用

**解决方案**:
```bash
# 使用不同端口
DATA_INGEST_METRICS_PORT=9092 python -m apps.backtest.data_prep.ingest_equity_1m_ibkr ...
```

**自动处理**: 代码已包含端口占用异常处理（warning日志，不中断）
