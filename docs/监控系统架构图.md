## 快速参考

### 关键URL
- Grafana: http://localhost:3000 (admin/admin123)
- Prometheus: http://localhost:9090
- Alertmanager: http://localhost:9093

### 常用PromQL
```promql
# 服务可用性
up{job="rt_engine"}

# 今日盈亏
pnl_realized_today_usd + pnl_unrealized_today_usd

# 订单转化率
sum(rate(orders_accepted_total[5m])) / sum(rate(orders_submitted_total[5m]))

# P95延迟
histogram_quantile(0.95, rate(bars_latency_seconds_bucket[5m]))
```

### 快速命令
```bash
# 启动
./deploy_monitoring.sh start

# 检查状态
./deploy_monitoring.sh status

# 查看日志
./deploy_monitoring.sh logs prometheus

# 热更新
./deploy_monitoring.sh reload
```
