## 本地环境自检清单

在运行任何回测/补数脚本前，先完成以下检查，确保数据库、缓存及 IBKR 连接正常。

### 1. 核对环境变量
- 命令：`cat .env`
- 核心项：`DATABASE_URL`, `REDIS_URL`, `IB_HOST`, `IB_PORT`, `IB_CLIENT_ID`, `IB_ACCOUNT`
- 预期：变量与目标环境一致（当前配置指向 `postgresql+psycopg2://option_user:option_pass@localhost:5433/option_us`、Redis `redis://localhost:6379/0`、IBKR `127.0.0.1:7497`）。

### 2. TimescaleDB（Postgres）连通性
- 命令：`pg_isready -h localhost -p 5433 -d option_us`
- 预期：返回 `accepting connections`
- 如需进一步校验权限，可执行  
  `PGPASSWORD=option_pass psql -h localhost -p 5433 -U option_user -d option_us -c "SELECT 1;"` → 结果为 `1`

### 3. Redis 连通性
- 命令：`redis-cli -u redis://localhost:6379/0 ping`
- 预期：`PONG`

### 4. IBKR TWS/Gateway 端口
- 命令：`nc -zv 127.0.0.1 7497`
- 预期：`Connection ... succeeded`（确保 TWS/Gateway 已登录且允许 API）
- 若端口关闭、提示失败，请确认 TWS 连接是否启动、API 端口设置与 `.env` 保持一致。

### 5. 关键表数据范围速览（可选）
- 命令：
  ```bash
  PGPASSWORD=option_pass psql -h localhost -p 5433 -U option_user -d option_us -c "
    SELECT 'bars1m_equity' AS table,
           MIN(ts_end)::date AS min_date,
           MAX(ts_end)::date AS max_date,
           COUNT(*) AS rows
    FROM bars1m_equity;
  "
  ```
- 预期（当前数据）：`min_date = max_date = 2024-01-03`，行数 6。若缺少目标交易日，请记录在缺口清单中待补数。

### 6. 自研服务健康检查（如已启动）
- 例：`curl -s http://localhost:8001/healthz | jq`
- 预期：HTTP 200，`{"ok":true,...}` 格式；若失败，需先启动对应服务或排查配置。

执行完成后，将输出（尤其是异常情况）记录在本地笔记或缺口清单中，作为后续补数据、联调的依据。
