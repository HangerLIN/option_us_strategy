# 数据管道与预处理开发文档

## 0. 硬性原则（No-Mock Policy）

- **唯一行情来源**：IB Gateway / TWS（`ibapi`）。生产环境严禁 `csv/parquet/yfinance/本地回放`。
- **唯一历史来源**：`reqHistoricalData`（barSize=1 min；盘前 Top5 用 `useRTH=0`；RTH 回补用 `useRTH=1`）。
- **唯一指数来源**：VIX 通过 IBKR Index 合约；拿不到时**关闭 E1**（追高 Gate 关闭）。
- **启动自检**：进程启动必须连通 IBGW、能订阅 VIX、`historicalDataEnd` 正常返回；任一失败**退出**并报警。
- **模拟开关**：生产环境不得存在任何“模拟/回放”开关。

------

## 1. 拓扑与节点

- **`md-gw`**：IBGW + `ib_client`（行情采集、历史/Scanner 调用、节流控制）
- **`rt-engine`**：分钟聚合、指标、Top5 计算（**只消费 IBKR 流/历史**）
- **`tsdb`**：TimescaleDB（**UTC**，`ts_end` 为分钟闭合戳）

------

## 2. 数据源与合约

- **股票 L1**：`reqMktData` + `genericTicks='233'`（RTVolume），拿到 bid/ask/last/volume/exchange；启动时获取 **minTick** 并缓存。
- **Scanner**：盘前取候选 ≤50（主板、价>5、美股），排除 ETF/ETN。
- **历史 1m**：Top5 用 `09:25–09:30` + `useRTH=0`；RTH 缺段回补仅允许最近 15 分钟窗口。
- **指数**：VIX（Index 合约），RTH 内**每分钟**采样一次（或订阅 L1）。
- **市值/基本面**：阈值（≥$20B/≥$100B）来源于合规快照或白名单；不可校验时**不入候选**。

------

## 3. 节流与会话治理（实盘关键）

- **统一节流器**：`historical_req_bucket`、`scanner_bucket`、`mktdata_sub_bucket` 三个令牌桶；支持**指数退避**与抖动；违约（pacing）进入冷却。
- **订阅管理**：Top5 之外的 symbol 不订阅；失焦立即退订；重连后按“关注列表”恢复订阅。
- **历史回补**：仅回补**≤15 分钟**的缺段；超过窗口则记录 DQ 告警并跳过。
- **断线恢复**：自动重连、对账未落地的 bars；若恢复失败进入“只出不入”保护模式（暂停 Top5 与指标更新）。

------

## 4. 时间/聚合/缺口口径（强一致）

- **时区**：库内 **UTC**；业务评估用 **US/Eastern**。
- **分钟闭合时间戳**：`ts_end = 分钟结束`（09:31 表示 09:30–09:31）。
- **1m 聚合**
  - 有成交→按分笔聚合 O/H/L/C/V；
  - 无成交→用当分钟 **NBBO mid** 补 O/H/L/C（`volume=0`）；
  - 禁止任何外部数据或启发式估计替代。
- **缺口回补**：只准用 `reqHistoricalData` 回补 ≤15 分钟；超出报警并跳过。

------

## 5. 指标集（全部落库，供信号/风控直接用）

- **必算**：`BOLL(20,2)`、`RSI(6/12/24)`、`ATR(14)`、`AO(5,34)`、`CCI(14,6)`（Woodies 基线）、`OBV(+EMA20)`、`RVOL(6)`、`MACD(12,26,9)`（含 `macd_line/signal/hist`）、`StochRSI(14,3,3)`（`stoch_rsi_k/stoch_rsi_d`）。
- **补算**：`MFI(14)`、`Stochastic(14,3)`（默认仅作为 **E1/E2 可选附加过滤**的输入）。
- **斜率派生（上层计算即可，不必落库）**：
  - `boll_dn_slope = boll_dn_t - boll_dn_{t-5}`（A3 “下轨趋平/上拐”）；
  - `mfi14_slope = mfi14_t - mfi14_{t-3}`（附加过滤）；
  - `boll_mid_slope = boll_mid_t - boll_mid_{t-5}`（结构辅助）。

**RVOL 基线作业**

- 16:10 用 `reqHistoricalData` 拉近 20 个交易日 RTH 分钟量，计算 `minute_index` 的均量，落 `rvol_baseline_eq`。
- `RVOL(6) = EMA6(volume / mean_vol_20d[minute_index])`（半日市自动缩短 `minute_index`）。

------

## 6. 盘前 Top5（F0｜严禁模拟）

- **09:30:01 ET 流程**
  1. Scanner 取候选 ≤50（主板、价>5、排 ETF/ETN）；
  2. `reqHistoricalData(1m,useRTH=0)` 拉 **09:25** bar + 昨日收盘价；
  3. 计算 **盘前涨幅**：`(price_0925 - prev_close) / prev_close`；
  4. 过滤：**市值阈值**（看涨 ≥$100B；其余 ≥$20B） + **M60 上行**（见 §8）；
  5. 入库 `premarket_top5`（只存 Top5）。

> 任一子步骤失败 → 当日 Top5 为空，上游 **E1/E2 不触发**（宁缺勿滥）。

------

## 7. 表与视图（与 DDL 对齐）

**表（维持最小集）**

- `bars1m_equity(ts_end, symbol, open, high, low, close, volume)`
- `indicators_eq_1m(ts_end, symbol, rsi6, rsi12, rsi24, boll_mid, boll_up, boll_dn, atr14, ao, stoch_k, stoch_d, cci14, cci6, obv, obv_ema20, mfi14, rvol6, macd_line, macd_signal, macd_hist, stoch_rsi_k, stoch_rsi_d)`
- `premarket_top5(trade_date, rank, symbol, ret_0925_0930)` —— `ret_0925_0930`字段存储**盘前涨幅**（09:25 vs 昨收）
- `rvol_baseline_eq(symbol, minute_index, mean_vol_20d)`
- （可选）`scanner_snapshot(ts, symbol, rank)`

**连续聚合视图（2 个）**

- `v_daily_ohlcv(symbol, trade_date, open_rth, high_rth, low_rth, close_rth, prev_close_rth)` —— 提供 A1 的 `open_today`、M60 与高开判断
- `v_daily_atr_pct(symbol, trade_date, atr_pct)` —— 财报前“横盘”判定（ATR%）

> 以上 CAGG 仅对 RTH 做 `time_bucket('1 day', ts_end ET)` 聚合，按日增量刷新。

------

## 8. A1/A3/财报前限定的**数据支撑**

- **A1 Gate（午后抄底总前置）**
  - **时间**：上层判断 `ts_end ≥ 14:00`；
  - **位置**：`close < v_daily_ohlcv.open_rth`；
  - **资格**：近 0–5 日 `premarket_top5` 存在该 symbol；
  - **限制**：若 `open_rth > prev_close_rth`（高开）**且** 当日期权价 > 当日期权开盘价 → 禁抄底。
- **A3 下轨转向**：上层用 `boll_dn_slope ≥ 0` 近似判断“下轨趋平/上拐”。
 
**AM 新增信号的数据支撑**

- `AM_BOTTOM_A1`：需要 `M5`（可由 1m 上层 `SMA5` 计算）及其线性回归斜率、`boll_dn` 斜率；局部低点识别窗口 `pivot_w`（默认 3）。
- `AM_SELL_C1`：基于“大阴线”参数化定义（`body_ratio`、`range_mult`）与 `boll_mid` 位置关系。
- `AM_CONFLUENCE_BUY_A2/SELL_S2`：需要 `MACD(12,26,9)` 三要素、`StochRSI`、`OBV/OBV_MA6`、`RSI6`、`BOLL`。
 
**隔夜修订的数据支撑**

- 布林带宽度收敛：`BWidth=(boll_up-boll_dn)/boll_mid`，需 1m 连续计算；按 `overnight.bw.ma` 与 `overnight.bw.lookback` 落地；可由上层实现为派生列。
- 日频视图：`v_daily_ohlcv_enriched(prev_close_rth)`、`v_daily_ma60(sma60, slope)`、可复用既有 `v_daily_ohlcv` 与新增 `sma60/slope` 派生。
- VIX：采样进入 `risk_state` 或单独表，由上层消费。
- **财报前“横盘或上涨”限定（仅做 T）**：
  - **上涨**：`M60` 上行（`close_rth > SMA60` 且斜率>0）；
  - **横盘**：`v_daily_atr_pct.atr_pct < preearn_atr_pct_max`（默认 2%）。

------

## 9. 调度与任务（SOP）

- **06:00**：刷新交易日历（半日市标记）；IBGW 健康检查。
- **09:30:01**：执行 Top5（§6）；落空则当日不上 E1/E2。
- **09:30–16:00**：每分钟闭合 → 写 `bars1m_equity` → 写 `indicators_eq_1m`。
- **每分钟**：VIX 采样/订阅刷新 Gate。
- **16:10**：刷新 `rvol_baseline_eq`；CAGG 重算 `v_daily_ohlcv` / `v_daily_atr_pct`。
- **任何时刻**：若与 IBGW 断连 → 进入“只出不入”保护，拉起自检通过后再恢复。

------

## 10. 质量与监控

- **延迟**：分钟闭合→入库 P95 ≤ **1.5s**；
- **缺失**：RTH 缺失分钟率 < **1%**；出现缺失按“NBBO mid 补”策略；
- **一致性**：`open_rth` = 当日第一根 RTH 1m **收盘**（建议取收盘避免插针）；
- **探针**：IBGW 可达、VIX 订阅、`historicalDataEnd` 正常返回；
- **报警**：Top5 空/历史回补失败/分钟缺失>阈值/与 IBGW 反复断连。

------

- `IB_HOST/PORT/CLIENT_ID/ACCOUNT`、`PAPER=1|0`

- `RVOL_BASELINE_DAYS=20`
- `SCANNER_MAX=50`、`SCANNER_WHITELIST_EXCH=主板`、`SCANNER_PRICE_MIN=5`
- `VIX_REQUIRED=true`（若 true 且订阅失败 → 退出；若 false → 订阅失败仅关闭 E1）

- **不改表**：确认 `indicators_eq_1m` 已包含 `mfi14 / stoch_k / stoch_d`。
- **新增 2 个 CAGG**：`v_daily_ohlcv`、`v_daily_atr_pct`。
