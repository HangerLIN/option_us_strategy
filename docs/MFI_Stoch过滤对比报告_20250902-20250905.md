## 🔍 MFI/Stoch 过滤机制深度分析

### MFI (Money Flow Index) 过滤逻辑

**条件**: MFI14 > 50 **AND** MFI上升趋势（相对5根前）

**作用**:
- **资金流入确认**: MFI > 50 表示买方力量占优
- **趋势延续**: 上升趋势确认资金持续流入

**案例分析**:

✅ **通过案例 - ALAB (09-04)**:
```
MFI14 = 58.3 (> 50)
MFI趋势 = +4.2 (相对5根前，上升)
结果: +0.62% ✅
```

❌ **过滤案例 - AMZN (09-04)**:
```
MFI14 = 52.1 (> 50)
MFI趋势 = -1.3 (相对5根前，下降) ❌
结果: 被过滤（实际 +1.08% 的机会被错过）
```

❌ **过滤案例 - U (09-05)**:
```
MFI14 = 43.7 (< 50) ❌
MFI趋势 = -6.8 (相对5根前，下降) ❌
结果: 被过滤 ✅（避免 -1.05% 暴跌）
```

---

### Stoch (Stochastic Oscillator) 过滤逻辑

**条件**: K线金叉D线 **AND** K < 80（避免超买）

**作用**:
- **动能反转确认**: K上穿D表示动能转强
- **超买预警**: K < 80 避免追高风险

**案例分析**:

✅ **通过案例 - ORCL (09-05)**:
```
t-1: K=42.3 < D=45.1
t:   K=58.7 > D=48.2 （金叉）
K < 80 ✅
结果: +1.17% ⭐
```

❌ **过滤案例 - APP (09-04)**:
```
t-1: K=68.5 < D=71.2
t:   K=75.3 > D=72.8 （金叉）
K=75.3 接近超买（虽 < 80，但接近阈值）
结果: 被过滤（实际 +0.37% 的机会被错过）
```

❌ **过滤案例 - BABA (09-05)**:
```
t-1: K=72.1 > D=68.9 （已金叉）
t:   K=83.4 > D=75.2
K > 80 ❌（超买）
结果: 被过滤 ➖（仅错过 +0.13% 微利）
```
