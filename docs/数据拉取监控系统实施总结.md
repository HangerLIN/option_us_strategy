   - 请求发送

3. `ingest_equity()` 添加监控参数，记录：
   - K线接收数量
   - K线存储数量
   - 指标计算时间（使用上下文管理器）
   - 指标计算完成
   - (symbol, date) 对完成
4. `main()` 函数：
   - 启动 Prometheus metrics server（端口9091）
   - 创建 `DataIngestionMonitor` 实例
   - 传递 monitor 到所有函数
   - 每批次完成后输出进度统计
   - 任务完成/失败时更新状态

**关键代码**:
```python
# 启动 metrics server
if metrics_enabled:
    start_metrics_server(metrics_port)
    LOGGER.info("Prometheus metrics server started on port %d", metrics_port)

# 创建监控器
monitor = DataIngestionMonitor(symbols=symbols, trade_dates=trade_dates, ...)

# 记录进度
monitor.record_bars_received(symbol, trade_date, len(records))
monitor.record_symbol_date_completed(symbol, trade_date)

# 输出统计
stats = monitor.get_stats()
LOGGER.info("📊 Progress: %d/%d symbols (%.1f%%), ETA: %.0fs", ...)
```

## 📋 完整指标清单

### 任务状态指标（3个）
- `data_ingest_task_status` - 任务状态（0=空闲,1=运行,2=完成,3=失败）
- `data_ingest_task_start_timestamp` - 启动时间戳
- `data_ingest_task_info` - 任务元数据（Info类型）

### 进度指标（8个）
- `data_ingest_completion_percentage` - 总体完成度(%)
- `data_ingest_symbols_total` - 总股票数
- `data_ingest_symbols_completed` - 已完成股票数
- `data_ingest_symbols_in_progress` - 处理中股票数
- `data_ingest_dates_total` - 总日期数
- `data_ingest_dates_completed` - 已完成日期数
- `data_ingest_symbol_date_pairs_total` - 总任务对数
- `data_ingest_symbol_date_pairs_completed_total` - 已完成任务对数

### K线数据指标（4个）
- `data_ingest_bars_requested_total` - K线请求总数（Counter）
- `data_ingest_bars_received_total` - K线接收总数（Counter）
- `data_ingest_bars_stored_total` - K线存储总数（Counter）
- `data_ingest_bars_count` - 每个(symbol,date)的K线数（Gauge）

### 指标计算指标（3个）
- `data_ingest_indicators_computed_total` - 已计算指标数（Counter）
- `data_ingest_indicators_failed_total` - 指标计算失败数（Counter）
- `data_ingest_indicator_computation_seconds` - 计算耗时（Histogram）

### IBKR连接指标（5个）
- `data_ingest_ibkr_connected` - 连接状态（1=连接,0=断开）
- `data_ingest_ibkr_errors_total` - IBKR错误总数（Counter）
- `data_ingest_ibkr_pacing_violations_total` - Pacing violations（Counter）
- `data_ingest_ibkr_retries_total` - 重试次数（Counter）
- `data_ingest_symbols_failed_total` - 失败股票数（Counter）

### 性能指标（4个）
- `data_ingest_rate_bars_per_second` - 拉取速率（bars/秒）
- `data_ingest_eta_seconds` - 预计完成时间（秒）
- `data_ingest_elapsed_seconds` - 已运行时长（秒）
- `data_ingest_batch_index` / `data_ingest_batch_total` - 批次进度

**总计**: **29个指标** ✅

## 🚀 使用方法

### 基本用法

```bash
# 1. 启动监控基础设施（如果未运行）
cd infra
docker-compose up -d prometheus grafana

# 2. 运行数据拉取（监控默认启用）
cd ..
python3 -m apps.backtest.data_prep.ingest_equity_1m_ibkr \
  --start 2025-10-02 \
  --end 2025-10-07 \
  --universe ref_market_cap:GLOBAL \
  --batch-size 3

# 3. 访问监控界面
# Grafana: http://localhost:3000 (admin/admin)
# Prometheus: http://localhost:9090
# Metrics: http://localhost:9091/metrics
```

```bash
# 自定义 metrics 端口
DATA_INGEST_METRICS_PORT=9092 \
python3 -m apps.backtest.data_prep.ingest_equity_1m_ibkr ...

python3 -m apps.backtest.data_prep.ingest_equity_1m_ibkr ...
```

## 📈 监控面板使用指南

### Dashboard: 📥 数据拉取进度监控

访问路径: Grafana → Dashboards → Data Ingestion Progress

#### 核心面板说明

1. **📊 总体进度**
   - 显示: 完成百分比（0-100%）
   - 颜色: 红(<30%) → 橙(30-60%) → 黄(60-90%) → 绿(>90%)
   - 用途: 快速了解整体进度

2. **⏱️ 预计完成时间 (ETA)**
   - 显示: 剩余秒数，自动转换为可读格式
   - 颜色: 绿(<30min) → 黄(30-60min) → 橙(1-2h) → 红(>2h)
   - 计算: 基于已完成任务的平均耗时

3. **📈 K线拉取速率**
   - 显示: 实时速率曲线（bars/秒）
   - 正常值: 10-20 bars/秒
   - 用途: 发现性能瓶颈

4. **🎯 股票处理进度**
   - 显示: 饼图（已完成/处理中/待处理）
   - 用途: 直观看到工作分布

5. **🔥 K线数量热力图**
   - 显示: 每个(symbol, date)的K线数量
   - 颜色: 深色=数据少，亮色=数据多
   - 用途: 发现数据缺失或异常

## 🔔 告警规则说明

### Critical 级别（需立即处理）

| 告警名称 | 触发条件 | 持续时间 | 处理建议 |
|---------|---------|---------|---------|
| DataIngestIBKRDisconnected | IBKR连接=0 | 1分钟 | 检查Gateway，检查网络 |
| DataIngestTaskFailed | 任务状态=失败 | 30秒 | 查看日志，排查错误 |

### Warning 级别（需关注）

| 告警名称 | 触发条件 | 持续时间 | 处理建议 |
|---------|---------|---------|---------|
| DataIngestStalled | 30min运行但5min无数据 | 5分钟 | 检查连接，检查进程 |
| DataIngestPacingViolations | Pacing>0.1次/秒 | 2分钟 | 增加延迟，减小批次 |
| DataIngestIndicatorFailureRate | 失败率>10% | 3分钟 | 检查DB，检查数据质量 |
| DataIngestSymbolFailures | >0.5个股票/分钟失败 | 5分钟 | 查看失败原因分布 |
| DataIngestIBKRErrorRate | >1个错误/秒 | 3分钟 | 检查IBKR状态 |

### Info 级别（供参考）

| 告警名称 | 触发条件 | 处理建议 |
|---------|---------|---------|
| DataIngestETATooLong | ETA>2小时 | 考虑分批处理 |
| DataIngestSlowIngestionRate | <5 bars/秒 | 优化性能 |
| 进度里程碑（50%, 90%） | - | 进度通知 |
