# 交易信号生成与组合构建

## 变更摘要（Changelog｜新增）

- 新增入场：`SIG_AM_BOTTOM_A1`（早盘抄底 1）
- 新增出场：`SIG_AM_SELL_C1`（早盘卖出 1）
- 新增入场：`SIG_AM_CONFLUENCE_BUY_A2`（早盘共振 2）
- 新增出场：`SIG_AM_CONFLUENCE_SELL_S2`（早盘共振卖出 2）
- 修订隔夜抄底：补充 IV、日级趋势、14:00 后布林带宽度收敛、两类触发路径（期权价强/弱）
- 优先级/互斥/冷却：为上列 4 个新信号补充优先级、与 E1/E2/A3/S1/S2 的冲突解决与冷却时间
- 回测口径：在 equity-only 与 options 两模式下的计算与度量（固定窗口与 TFE 两套）

## 0) 全局

- **频率/时区**：1m 主频；业务时区 US/Eastern（数据库存 UTC），`ts_end` = 分钟结束时刻。
- **指标与参数**：`BOLL(20,2)`；`RSI(6/12/24)`；`ATR(14)`；`AO(5,34)`；`CCI(14,6)`；`OBV(+EMA20)`；`RVOL(6)`（20D 分时基线）；**`MFI(14)`；`Stoch(14,3)`**。
- **过滤主规则**：**AO>0 且上行**、**CCI14>0 & CCI6>0**、**OBV>EMA20**，**满足其二**。
- **附加过滤（可开关）**：`feature.mfi_stoch_filter=false`（默认关闭）。开启时，E1/E2 还需满足 **MFI/Stoch 二选一**（见下）。
- **风控前置**：`VIX < 20` 方可触发 E1（追高）；期权仅做 **DTE 2–7、OTM +2~+5**（可选：`Δ≈0.35–0.45`），**OI≥500、Vol≥100、价差 ≤ max($0.10, 5%)**。

## 术语与口径（新增/沿用）

- M5：以 1m K 聚合的 `SMA(5)`。
- M5 线性回归斜率：`LR_slope(M5, K=5)`，单位“价格/分钟”。
- BOLL：参数 `(n=20, k=2.0)`，中轨 `MID=SMA(20)`，上/下轨 `UP/DN`。
- BOLL 下轨斜率：`slope(DN, K=5)`。
- 局部最低点（Pivot Low）：窗口 `[t−w, t+w]` 内 `low(t)` 为局部最小且趋势由下转上，默认 `w=3`。
- 大阴线（参数化）：`bearish(close<open)` 且 `body_ratio=|close-open|/(high-low)≥0.6` 且 `range≥1.5×median(range,20)`（阈值可配）。
- StochRSI：底层 `RSI(14)`，`(n=14,k=3,d=3)`，阈值线 20/80。
- OBV_MA(6)：`OBV` 的 `MA(6)`。
- RVOL(6)：滚动 6 分钟相对成交量指标。
- VWAP：当日成交量加权平均价（RTH 内）。
- 实现口径：斜率与窗口均在 1m 级别计算；时间判断使用 ET（America/New_York），`ts_end` 为分钟闭合。

## F0｜候选池（唯一参赛名单）

- **盘前 Top5**：取 **09:25 相比昨日收盘价的涨幅**前 5 名（`premarket_top5`）。计算公式：`(price_0925 - prev_close) / prev_close`。
- **市值/趋势**：做看涨期权的正股 **市值≥$100B**；其它操作 **≥$20B**；日线 `M60` 上行（`Close>SMA60` 且斜率>0）。
- **（可选）盘前量价确认**：OBV 斜率 > 0 或 OBV>EMA20，`RVOL(6) ≥ 1.5`（默认关闭）。

------

## E1｜开盘追高（09:31 评估） → `SIG_OPEN_CHASE_BUY`

- **条件**：09:28–09:30 **两根阳线且后一根收更高**；**或** 两根 K 的**开盘价均 ≥ BOLL 中轨开盘**。
- **过滤**：主规则“三选二”；且 **`VIX < 20`**。
- **附加过滤（开关生效时）**：满足下列**任一**：
  - `MFI14 > 50` **且** `mfi14_slope > 0`（近 3 根斜率）；**或**
  - `Stoch_K 上穿 Stoch_D` **且** `Stoch_K < 80`。
- **期权**：`DTE 2–7，OTM +2~+5`（可选 `Δ≈0.35–0.45`），**OI≥500、Vol≥100、价差 ≤ max($0.10, 5%)**。

------

## E2｜盘前两根大阴 → 回补买入 `SIG_REBOUND_BUY`

- **大阴判定**：价 < $100：`跌速 ≥ 1%/min`；价 ≥ $100：`≥ 0.5%/min`；且 **实体 ≥ 1×ATR14**。
- **触发 A**：09:33 前稳住，**RSI6 上穿 30**。
- **触发 B**：10:00–10:30 出现**第二个更低低点**后 **轻微反弹（≤0.5×ATR14）**。
- **过滤**：`RVOL(6) ≥ 2`、`OBV 上穿 EMA20`、`AO 由负转正` **任选二**。
- **附加过滤（开关生效时）**：与 E1 相同（二选一通过）。

## AM 早盘信号（新增）

### SIG_AM_BOTTOM_A1 —— 早盘抄底买入（规则 1）

动机：早盘冲击后形成双重更低低点（L1→L2），同时趋势由下转上，尝试抄底反弹。

判定口径（全部满足）

- 局部最低点序列：在 1m 上识别两个连续局部低点 L1、L2（相邻 pivot，无更低低点插入），且 `low(L2) < low(L1)`。
- 趋势条件：于 `L2` 时刻，`LR_slope(M5,5) > 0` 且 `slope(DN,5) > 0`。
- 确认条件：`L1→L2` 间 `M5` 与 `DN` 斜率先连续 ≥6 根为负，随后在 `L2` 附近连续 ≥3 根为正（允许 ±1 根抖动）。

触发与入场

- 触发点：`t = L2` 闭合后一根 `t+1` 的 close 确认后入场（避“尖钉”）。
- 可选过滤（默认开）：`close(t+1) ≥ MID(t+1)`（弱反弹过滤）。

优先选择（Option 侧）

- 对满足条件的股票，按 `slope(DN,5)` 从大到小排序取前 `topN`（默认 3）。
- 选 2–7 DTE、价差档位 `+2 ~ +5` OTM 的当日成交量最高的看涨合约（`OI≥500, Vol≥100, spread≤max($0.10, 5%*mid)`）。
- equity-only 回测仅打点，不做期权选择。

冷却/TTL：同 symbol 冷却 10 分钟；`TTL=180s`。

参数（risk_limits）：`am_bottom.pivot_w=3`，`am_bottom.neg_seq_min=6`，`am_bottom.pos_seq_min=3`，`am_bottom.allow_mid_filter=true`，`am_bottom.topN=3`，`am_bottom.cooldown_s=600`。

---

### SIG_AM_SELL_C1 —— 早盘卖出（规则 1）

动机：早盘出现强趋势下压（连续大阴线），且价格整体处于 `BOLL MID` 下方，触发卖出/平多。

判定口径（全部满足）

- 连续 `am_sell1.consecutive` 根“大阴线”（默认 2）。
- 这两根的 K 区间整体位于 `MID` 下方（`max(high[-2],high[-1]) < MID[-1]`）。

触发与出场：第二根“大阴线”闭合时触发；用于卖出 Call / 平多；equity-only 记出场信号。

参数：`am_sell1.body_ratio_min=0.6`，`am_sell1.range_mult_min=1.5`，`am_sell1.consecutive=2`。

---

### SIG_AM_CONFLUENCE_BUY_A2 —— 早盘共振买入（规则 2）

动机：短时多维度共振（位置/动能/超卖/时机/量能），在最近 5 根 1m 内全部成立时入场。

判定条件（全部满足，顺序不强制）

- 位置：`price ≥ MID`，且一次回踩 `MID` 或 `UP` 获支撑（`low ≤ MID 且 close ≥ MID` 或 `low ≤ UP 且 close ≥ UP`）。
- 动能：`MACD(12,26,9)` 金叉，绿柱缩窄后红柱首次出现（`hist` 由负转正）。
- 超卖反转：`RSI(6)` 自 `<30` 区域上穿 `30`。
- 时机：`StochRSI` 的 `%K` 或 `%D` 自 `<20` 上穿 `20`。
- 量能：`OBV` 过去 `w=5` 内斜率 > 0（`LR_slope(OBV,5)>0` 或 `OBV>OBV_MA(6)` 且斜率>0）。
- 时间窗：上述 1–5 必须在最近 `lookback_n=5` 根 1m 内全部出现，以最后一个条件成立时刻为触发点。

冷却/TTL：同 symbol 冷却 10 分钟；`TTL=180s`。

参数：`am_conf.buy.lookback_n=5`，`am_conf.buy.obv_slope_w=5`。

---

### SIG_AM_CONFLUENCE_SELL_S2 —— 早盘共振卖出（规则 2）

动机：与上条对偶的出场共振。

判定条件（全部满足）

- 位置：跌破 `MID`，并反弹至 `MID` 受压或跌破 `DN`。
- 超买反转：`RSI(6)` 自 `>70` 区域下穿 `70`。
- 时机：`StochRSI` 的 `%K` 或 `%D` 自 `>70` 下穿 `70`。
- 量能：`OBV` 与 `OBV_MA(6)` 死叉，且 `OBV` 斜率 < 0。
- 时间窗：最近 `lookback_n=5` 根 1m 内全部出现，取最后成立时刻为触发点。

参数：`am_conf.sell.lookback_n=5`。

## 午后抄底（≥14:00）

- **A1（前置条件，\*不发单\*）**

  - 时间：`time ≥ 14:00`
  - 位置：`close < open_today`
  - 资格：最近 `0–5` 个交易日 **曾进入 `premarket_top5`**
  - 限制：当日**高开**且**期权价 > 当日开盘价** → **禁止抄底**

  > 仅作为 **A2/A3/A4 的 Gate**；A1 未通过时不评估任何午后买点（`reason.a1_gate=false`）。

- **A2 → `SIG_PM_BOTTOM_A2`**：识别**第二/第三局部高点**后**轻微反弹**；过滤 **（任二）**：`RSI6 上穿 40`、`AO 由负转正`、`CCI14>0`。

- **A3 → `SIG_PM_BOTTOM_A3`**：BOLL **下轨趋平/上拐** + 一根阴线**穿下轨**后，下一根**大阳线**收回下轨上。

- **A4 → `SIG_PM_BOTTOM_A4`**：`RVOL(6)` **双峰**（两峰 **≥ 3×** 分时基线，间隔 **≥ 5 分钟**），第二峰回落后**轻微反弹**。

- **限制**：若当日**高开**，14:00 后当期权价**高于当日开盘价** → **禁买看涨**。

## 卖点与时间纪律

- **S2（早盘专属）**：持有 E1 仓位时，出现 **连续两根 1m 收盘价回踩上轨** → **卖出**。
- **S1（通用）**：价格**在上轨外运行 ≥1 根整 K** 后，**首次回到中轨** → **卖出**。
- **时间清仓**：**12:00–14:00 禁开新仓**；**14:00 前** 清掉“开盘追高”仓位；隔夜持仓**次日 12:00 前** 必清。

## 隔夜管理

- **平/小波动（-0.5%~+0.5%）** → **09:30 首根RTH K线闭合立刻清仓**（`SIG_OVERNIGHT_GAP_EXIT`）；
- **低开 ≥1%** → **清看涨 + 买平值/轻虚值看跌**；当 **整根 K 在上轨上 → 首次回踩上轨** 卖掉当日看跌；
- **当日期权价 < 昨日抄底价** → **无条件止损**；**高开且无大单延续** → 开盘可卖半仓；
- 企稳后 **整根 K 上轨上 → 首次回踩上轨** **清全仓**，并设 **8% 追踪止盈**（从最高点回落 8% 全清）；
- **`IV>100%` 的看涨** → **禁止隔夜**（收盘前强平）。

### 隔夜抄底（修订版概述）

- 资格硬门槛（全部满足）：期权 `IV ≤ 100%`；日级趋势：连续 3 天日 K 收于 `M20` 上方，且 `M60` 斜率 > 0；`VIX Gate`：`enforce|record|ignore`（默认 enforce）。
- 带宽收敛（1m，BOLL 20/2）：`BWidth=(UP-DN)/MID`；`bw5=ma(bw,5)`；若 `bw5 < 0.5×mean(bw,120m)` 且持续 ≥10 分钟 → “趋稳”。
- 触发路径 A（期权价强）：10:00–15:00 股价持续在 `VWAP` 上方；`t≥15:40` 且 `price≤MID` 且 `RSI6` 上穿 30 → 市价买入。
- 触发路径 B（期权价弱）：趋稳后识别“局部高点”，第二/第三个局部高点的 12 分钟总量不高于第一个；回落后出现轻微反弹（≤0.5%）即触发；或 14:00 后 `RVOL(6)` 出现两次 ≥3× 峰后轻微反弹触发；下单采用限价（mid 起，按执行分层补价）。
- 回测 equity-only 下仅记录资格/触发与 TFE/固定窗收益，不建期权仓位。

## 组合与仓位

- **并发上限**：开盘 10 分钟内最多重仓 **3 只**（F0 Top5 中按 **盘前涨幅（09:25 vs 昨收）** 优先；并列时依次看 **09:31 的 RVOL6（高优先）→ 当时期权价差（小优先）→ 当时成交量（高优先）**）。
- **仓位**：单标的初始 **1R**（账户权益 0.5%–1% 风险）；满足“再触发 + `AO 上行 & OBV 抬升 & RVOL ≥ 2`”**仅加一次**，最多 **2R**。
- **止损**：期权 **硬止损 −8%**；若对应正股下行 **0.5×ATR14** 的 `Δ` 估算损失更紧，则取更紧者。

## 冲突与优先级（更新）

- **总体优先级（高→低）**：
  - 卖点/强制退出：`SIG_AM_SELL_C1`、`SIG_AM_CONFLUENCE_SELL_S2`、`S1/S2`、风控强平
  - 既有体系：`E1/E2`、`A3`
  - 新增入场：`SIG_AM_BOTTOM_A1`、`SIG_AM_CONFLUENCE_BUY_A2`
- **互斥**：同 symbol 若存在待处理卖点时，优先消费卖点后再评估买入。
- **冷却**：四个新增信号各自独立冷却 10 分钟；若某买入失败（风控/执行），对同 symbol 的次级买入需等待冷却期。
- **同分钟冲突**：卖点（`SIG_EXIT_*`、`SIG_TIME_CLEAR_*`）优先于买入。
- **风控前置**：`VIX ≥ 20` 关闭 E1；12:00–14:00 禁开；逐标的封禁（MIDFAIL/MISSED_ENTRY）以风控判定为准。

## 信号输出契约（给执行/风控）

   `SIG_OPEN_CHASE_BUY` / `SIG_REBOUND_BUY` / `SIG_PM_BOTTOM_A2|A3|A4` /

   `SIG_EXIT_UPPER_TAP_X2` / `SIG_EXIT_BOX2MID` / `SIG_TIME_CLEAR_12_14` / `SIG_OVERNIGHT_*`
   
   **信号代码说明**：
   - `SIG_OPEN_CHASE_BUY`：开盘追高买入（E1）—— 09:31 评估，09:28–09:30 两根阳线且后一根收更高，或两根K开盘价均≥BOLL中轨；需通过 VIX<20 及主规则"三选二"过滤
   - `SIG_REBOUND_BUY`：回补买入（E2）—— 盘前两根大阴线后，触发A：09:33前 RSI6上穿30；或触发B：10:00–10:30 第二个更低低点后轻微反弹（≤0.5×ATR14）
   - `SIG_PM_BOTTOM_A2`：午后抄底A2 —— ≥14:00，识别第二/第三局部高点后轻微反弹；需满足（任二）：RSI6上穿40 / AO负转正 / CCI14>0
   - `SIG_PM_BOTTOM_A3`：午后抄底A3 —— ≥14:00，BOLL下轨趋平/上拐 + 一根阴线穿下轨后，下一根大阳线收回下轨之上
   - `SIG_PM_BOTTOM_A4`：午后抄底A4 —— ≥14:00，RVOL(6)双峰（两峰≥3×分时基线，间隔≥5分钟），第二峰回落后轻微反弹
   - `SIG_AM_BOTTOM_A1`：早盘抄底1 —— 连续两局部低点且 L2 更低；`L1→L2` 斜率先负≥6 根、后正≥3 根；`L2` 后一根收盘确认入场；可选 `close≥MID` 过滤；冷却 10 分钟
   - `SIG_AM_SELL_C1`：早盘卖出1 —— 连续两根“大阴线”且整体位于 `MID` 下方，第二根闭合时触发
   - `SIG_AM_CONFLUENCE_BUY_A2`：早盘共振买入 —— 位置/动能/超卖/时机/量能五要素在 `5` 根内全部出现，最后成立时刻触发；冷却 10 分钟
   - `SIG_AM_CONFLUENCE_SELL_S2`：早盘共振卖出 —— 与上条对偶：跌破 `MID`、RSI/ StochRSI 超买回落、OBV 死叉且斜率<0，`5` 根内共振
   - `SIG_EXIT_UPPER_TAP_X2`：卖出S2（早盘专属）—— 持有E1仓位时，连续两根1m收盘价回踩上轨
   - `SIG_EXIT_BOX2MID`：卖出S1（通用）—— 价格在上轨外运行≥1根整K后，首次回到中轨
   - `SIG_TIME_CLEAR_12_14`：时间清仓 —— 12:00–14:00禁开新仓；14:00前清掉"开盘追高"仓位
   - `SIG_OVERNIGHT_*`：隔夜管理 —— 包括平/小波动清仓、低开对冲、上轨回踩清全仓、8%追踪止盈、IV>100%禁隔夜等规则

- `symbol`, `ts_end`
- `reason`：关键触发要点（如 `two_green=true`, `rsi6_cross_30=true`, `two_upper_tap=true`, **`mfi_stoch_filter_pass=true/false`**）
- `option_hint`：`dte=2-7, otm_steps=2-5`（**可选**：`delta=0.35–0.45`）
- `risk_hint`：`size=1R`, `max_total=2R`, `stop=-8%`
- `ttl=180s`, `cooldown=600s`

### 附录 A｜机器口径（落地到 `engine.py`）

- **两根阳线**：`close_t>open_t && close_{t-1}>open_{t-1}`
- **两根回踩上轨**：`close_t < upper_t && close_{t-1} < upper_{t-1}`
- **整根K在上轨上**：`low_t > upper_t`
- **首次回到中轨**：`low_t <= mid_t <= high_t && close_t >= mid_t`（过滤插针）
- **大阴实体**：`|close-open| ≥ 1×ATR14` 且跌速阈值满足（<$100：≥1%/min；≥$100：≥0.5%/min）
- **轻微反弹**：最近低点→当前高点幅度 `≤ 0.5×ATR14`
- **RSI6 上穿 30**：`rsi6_{t-1}<30 && rsi6_t≥30`
- **RVOL 双峰**：近 90 分钟内两峰 `≥3×` 分时基线且间隔 `≥5` 分钟
- **MFI 斜率**：`mfi14_slope = mfi14_t - mfi14_{t-3} > 0`
- **Stoch 上穿**：`stoch_k_{t-1} ≤ stoch_d_{t-1} 且 stoch_k_t > stoch_d_t`，并 `stoch_k_t < 80`
