# 交易信号生成与组合构建

## 0) 全局

- **频率/时区**：1m 主频；业务时区 US/Eastern（数据库存 UTC），`ts_end` = 分钟结束时刻。
- **指标与参数**：`BOLL(20,2)`；`RSI(6/12/24)`；`ATR(14)`；`AO(5,34)`；`CCI(14,6)`；`OBV(+EMA20)`；`RVOL(6)`（20D 分时基线）；**`MFI(14)`；`Stoch(14,3)`**。
- **过滤主规则**：**AO>0 且上行**、**CCI14>0 & CCI6>0**、**OBV>EMA20**，**满足其二**。
- **附加过滤（可开关）**：`feature.mfi_stoch_filter=false`（默认关闭）。开启时，E1/E2 还需满足 **MFI/Stoch 二选一**（见下）。
- **风控前置**：`VIX < 20` 方可触发 E1（追高）；期权仅做 **DTE 2–7、OTM +2~+5**（可选：`Δ≈0.35–0.45`），**OI≥500、Vol≥100、价差 ≤ max($0.10, 5%)**。

------

## F0｜候选池（唯一参赛名单）

- **盘前 Top5**：取 **09:25 相比昨日收盘价的涨幅**前 5 名（`premarket_top5`）。计算公式：`(price_0925 - prev_close) / prev_close`。
- **市值/趋势**：做看涨期权的正股 **市值≥$100B**；其它操作 **≥$20B**；日线 `M60` 上行（`Close>SMA60` 且斜率>0）。
- **（可选）盘前量价确认**：OBV 斜率 > 0 或 OBV>EMA20，`RVOL(6) ≥ 1.5`（默认关闭）。

------

## E1｜开盘追高（09:31 评估） → `SIG_OPEN_CHASE_BUY`

- **条件**：09:28–09:30 **两根阳线且后一根收更高**；**或** 两根 K 的**开盘价均 ≥ BOLL 中轨开盘**。
- **过滤**：主规则“三选二”；且 **`VIX < 20`**。
- **附加过滤（开关生效时）**：满足下列**任一**：
  - `MFI14 > 50` **且** `mfi14_slope > 0`（近 3 根斜率）；**或**
  - `Stoch_K 上穿 Stoch_D` **且** `Stoch_K < 80`。
- **期权**：`DTE 2–7，OTM +2~+5`（可选 `Δ≈0.35–0.45`），**OI≥500、Vol≥100、价差 ≤ max($0.10, 5%)**。

------

## E2｜盘前两根大阴 → 回补买入 `SIG_REBOUND_BUY`

- **大阴判定**：价 < $100：`跌速 ≥ 1%/min`；价 ≥ $100：`≥ 0.5%/min`；且 **实体 ≥ 1×ATR14**。
- **触发 A**：09:33 前稳住，**RSI6 上穿 30**。
- **触发 B**：10:00–10:30 出现**第二个更低低点**后 **轻微反弹（≤0.5×ATR14）**。
- **过滤**：`RVOL(6) ≥ 2`、`OBV 上穿 EMA20`、`AO 由负转正` **任选二**。
- **附加过滤（开关生效时）**：与 E1 相同（二选一通过）。

------

## 午后抄底（≥14:00）

- **A1（前置条件，\*不发单\*）**

  - 时间：`time ≥ 14:00`
  - 位置：`close < open_today`
  - 资格：最近 `0–5` 个交易日 **曾进入 `premarket_top5`**
  - 限制：当日**高开**且**期权价 > 当日开盘价** → **禁止抄底**

  > 仅作为 **A2/A3/A4 的 Gate**；A1 未通过时不评估任何午后买点（`reason.a1_gate=false`）。

- **A2 → `SIG_PM_BOTTOM_A2`**：识别**第二/第三局部高点**后**轻微反弹**；过滤 **（任二）**：`RSI6 上穿 40`、`AO 由负转正`、`CCI14>0`。

- **A3 → `SIG_PM_BOTTOM_A3`**：BOLL **下轨趋平/上拐** + 一根阴线**穿下轨**后，下一根**大阳线**收回下轨上。

- **A4 → `SIG_PM_BOTTOM_A4`**：`RVOL(6)` **双峰**（两峰 **≥ 3×** 分时基线，间隔 **≥ 5 分钟**），第二峰回落后**轻微反弹**。

- **限制**：若当日**高开**，14:00 后当期权价**高于当日开盘价** → **禁买看涨**。

------

## 卖点与时间纪律

- **S2（早盘专属）**：持有 E1 仓位时，出现 **连续两根 1m 收盘价回踩上轨** → **卖出**。
- **S1（通用）**：价格**在上轨外运行 ≥1 根整 K** 后，**首次回到中轨** → **卖出**。
- **时间清仓**：**12:00–14:00 禁开新仓**；**14:00 前** 清掉“开盘追高”仓位；隔夜持仓**次日 12:00 前** 必清。

------

## 隔夜管理

- **平/小波动（-0.5%~+0.5%）** → **开盘清**；
- **低开 ≥1%** → **清看涨 + 买平值/轻虚值看跌**；当 **整根 K 在上轨上 → 首次回踩上轨** 卖掉当日看跌；
- **当日期权价 < 昨日抄底价** → **无条件止损**；**高开且无大单延续** → 开盘可卖半仓；
- 企稳后 **整根 K 上轨上 → 首次回踩上轨** **清全仓**，并设 **8% 追踪止盈**（从最高点回落 8% 全清）；
- **`IV>110%` 的看涨** → **禁止隔夜**（收盘前强平）。

------

## 组合与仓位

- **并发上限**：开盘 10 分钟内最多重仓 **3 只**（F0 Top5 中按 **盘前涨幅（09:25 vs 昨收）** 优先；并列时依次看 **09:31 的 RVOL6（高优先）→ 当时期权价差（小优先）→ 当时成交量（高优先）**）。
- **仓位**：单标的初始 **1R**（账户权益 0.5%–1% 风险）；满足“再触发 + `AO 上行 & OBV 抬升 & RVOL ≥ 2`”**仅加一次**，最多 **2R**。
- **止损**：期权 **硬止损 −8%**；若对应正股下行 **0.5×ATR14** 的 `Δ` 估算损失更紧，则取更紧者。

------

## 冲突与优先级

- **同分钟冲突**：卖点（`SIG_EXIT_*`、`SIG_TIME_CLEAR_*`）**优先于** 买入。
- **风控前置**：`VIX ≥ 20` 关闭 E1；12:00–14:00 禁开；逐标的封禁（MIDFAIL/MISSED_ENTRY）以风控判定为准。

------

## 信号输出契约（给执行/风控）

- `signal_code`：
   `SIG_OPEN_CHASE_BUY` / `SIG_REBOUND_BUY` / `SIG_PM_BOTTOM_A2|A3|A4` /
   `SIG_EXIT_UPPER_TAP_X2` / `SIG_EXIT_BOX2MID` / `SIG_TIME_CLEAR_12_14` / `SIG_OVERNIGHT_*`
   
   **信号代码说明**：
   - `SIG_OPEN_CHASE_BUY`：开盘追高买入（E1）—— 09:31 评估，09:28–09:30 两根阳线且后一根收更高，或两根K开盘价均≥BOLL中轨；需通过 VIX<20 及主规则"三选二"过滤
   - `SIG_REBOUND_BUY`：回补买入（E2）—— 盘前两根大阴线后，触发A：09:33前 RSI6上穿30；或触发B：10:00–10:30 第二个更低低点后轻微反弹（≤0.5×ATR14）
   - `SIG_PM_BOTTOM_A2`：午后抄底A2 —— ≥14:00，识别第二/第三局部高点后轻微反弹；需满足（任二）：RSI6上穿40 / AO负转正 / CCI14>0
   - `SIG_PM_BOTTOM_A3`：午后抄底A3 —— ≥14:00，BOLL下轨趋平/上拐 + 一根阴线穿下轨后，下一根大阳线收回下轨之上
   - `SIG_PM_BOTTOM_A4`：午后抄底A4 —— ≥14:00，RVOL(6)双峰（两峰≥3×分时基线，间隔≥5分钟），第二峰回落后轻微反弹
   - `SIG_EXIT_UPPER_TAP_X2`：卖出S2（早盘专属）—— 持有E1仓位时，连续两根1m收盘价回踩上轨
   - `SIG_EXIT_BOX2MID`：卖出S1（通用）—— 价格在上轨外运行≥1根整K后，首次回到中轨
   - `SIG_TIME_CLEAR_12_14`：时间清仓 —— 12:00–14:00禁开新仓；14:00前清掉"开盘追高"仓位
   - `SIG_OVERNIGHT_*`：隔夜管理 —— 包括平/小波动清仓、低开对冲、上轨回踩清全仓、8%追踪止盈、IV>110%禁隔夜等规则

- `symbol`, `ts_end`
- `reason`：关键触发要点（如 `two_green=true`, `rsi6_cross_30=true`, `two_upper_tap=true`, **`mfi_stoch_filter_pass=true/false`**）
- `option_hint`：`dte=2-7, otm_steps=2-5`（**可选**：`delta=0.35–0.45`）
- `risk_hint`：`size=1R`, `max_total=2R`, `stop=-8%`
- `ttl=180s`, `cooldown=600s`

------

### 附录 A｜机器口径（落地到 `engine.py`）

- **两根阳线**：`close_t>open_t && close_{t-1}>open_{t-1}`
- **两根回踩上轨**：`close_t < upper_t && close_{t-1} < upper_{t-1}`
- **整根K在上轨上**：`low_t > upper_t`
- **首次回到中轨**：`low_t <= mid_t <= high_t && close_t >= mid_t`（过滤插针）
- **大阴实体**：`|close-open| ≥ 1×ATR14` 且跌速阈值满足（<$100：≥1%/min；≥$100：≥0.5%/min）
- **轻微反弹**：最近低点→当前高点幅度 `≤ 0.5×ATR14`
- **RSI6 上穿 30**：`rsi6_{t-1}<30 && rsi6_t≥30`
- **RVOL 双峰**：近 90 分钟内两峰 `≥3×` 分时基线且间隔 `≥5` 分钟
- **MFI 斜率**：`mfi14_slope = mfi14_t - mfi14_{t-3} > 0`
- **Stoch 上穿**：`stoch_k_{t-1} ≤ stoch_d_{t-1} 且 stoch_k_t > stoch_d_t`，并 `stoch_k_t < 80`

------
