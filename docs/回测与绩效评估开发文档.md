# 回测与绩效评估

## 1) 目标与边界

- **目标**：对“开盘追高 / 回补 / 午后抄底 / 卖点 / 隔夜”五类规则做**事件级回放**，产出**可审计交易明细**与**分策略绩效**；验证“信号→执行→风控”的闭环在历史数据上的一致性与成本。
- **边界**：仅覆盖**回放时钟、信号生成、成交模拟、风控约束、成本模型与报表**；不做参数大规模寻优。

------

## 2) 技术选型与数据依赖

- **核心表**：`bars1m_equity`, `indicators_eq_1m`, `bt_top5`（回测生成的盘前候选）, `dim_trading_calendar`
- **可选表**：`bars1m_option`（若落库，含 bid/ask/iv/delta/theta/oi/vol）
- **新增视图（若已按数据管道文档创建）**：
  - `v_daily_ohlcv(symbol, trade_date, open_rth, high_rth, low_rth, close_rth, prev_close_rth)` —— A1 Gate、M60、是否高开
  - `v_daily_atr_pct(symbol, trade_date, atr_pct)` —— 财报前“横盘”判定
- **两种模式**：
  1. **逻辑回放（推荐）**：按规则当场重算信号（不依赖 `signals`）
  2. **信号回放**：直接复用实盘 `signals`，仅模拟执行与成本
  3. **equity-only vs options**：
     - equity-only：仅记录信号与标的价格表现（固定窗口与 TFE 两套），不创建期权仓位
     - options：按合约筛选（2–7 DTE、OTM +2~+5、OI/Vol/Spread 门槛）模拟成交与 PnL

------

## 3) 数据快照与回放时钟

- **日历**：用 `dim_trading_calendar` 锁定当日 RTH 开/收（含半日市）。
- **仿真时钟**：逐分钟推进 `ts_end`，每分钟执行：
  1. **盘前（09:25–09:30）**：拉 1m 历史，算“最后 5 分钟涨幅”→ `bt_top5`（按 Universe & M60/市值过滤）
  2. **RTH**：执行时间窗（12:00–14:00 禁新开），生成/回放信号（F0→E1/E2→A1→A2/A3/A4→S1/S2→时间/隔夜），驱动**执行模拟**与**风控约束**（−8%、14:00 清追高、IV>110% 禁隔夜、封禁等），产出成交

------

## 4) 信号生成（与实盘一致 + A1/MFI-Stoch 选项）

> **统一过滤**：AO/CCI/OBV 三选二；**TTL=180s**、**冷却=600s**；`VIX≥20` 关闭 E1

- **F0 候选**：09:25–09:30 Top5（市值阈值 + M60 上行）。
- **E1**（09:31）：两阳或“盘前开盘价≥中轨”；过滤三选二；`VIX<20`。
- **E2**：两根大阴后 RSI6↑30 **或** 二次更低点 + 轻反弹（≤0.5×ATR14）；过滤二选二（RVOL/OBV上穿/AO负转正）。
- **A1（前置 Gate，\**不发单\**）**：`ts_end≥14:00` **且** `close<open_rth` **且** 近 0–5 日**进入过 Top5**；若当日**高开**且**期权价>当日开盘价** → 禁抄底；A1 未通过则 **不评估** A2/A3/A4。
- **A2**：第二/第三局部高点后轻反弹；（任二）RSI6↑40/AO负转正/CCI14>0。
- **A3**：下轨趋平或上拐（近 5 根 `boll_dn_slope≥0`）+ 阴穿下轨，下一根阳线收回下轨上。
- **A4**：RVOL(6) 双峰（两峰≥3×基线、间隔≥5 分钟），第二峰回落后轻反弹。
- **卖点**：S2（早盘持仓出现**连续两根回踩上轨**）；S1（上轨外箱体→首次回中轨）。
- **AM 新增**：
  - `SIG_AM_BOTTOM_A1`：双底更低 + 斜率先负后正 + `close≥MID` 可选过滤；TTL=180s，冷却 600s
  - `SIG_AM_SELL_C1`：连续两根“大阴线”且整体在 `MID` 下方
  - `SIG_AM_CONFLUENCE_BUY_A2`：位置/动能/超卖/时机/量能在 5 根内共振
  - `SIG_AM_CONFLUENCE_SELL_S2`：与上条对偶（跌破 MID、RSI/StochRSI 超买回落、OBV 死叉）
- **隔夜**：G1/G2/G3/G5/G6/G7 原样执行（平/小波动清、低开对冲、上轨回踩清全仓、8% 追踪止盈、IV>110% 禁隔夜）。
- **（可选）附加过滤**：`feature.mfi_stoch_filter=true` 时，E1/E2 需 **额外**满足
  - `MFI14>50` 且 `mfi14_slope>0` **或** `Stoch_K 上穿 Stoch_D 且 Stoch_K<80`（默认关闭）

------

## 5) 成交模拟（与《执行与成本控制》一致）

> **只用 L1（bid/ask/mid）** 做撮合；与实盘完全同价构/同 TTL/同撤补路径

### 5.1 价格与路径

- **可成交限价**：买入 `min(ask, mid+0.6*spread)`；卖出对称；均按 `minTick` 对齐
- **被动→半主动**：起始 `mid`；15s 无排队优势 → `mid+0.2*spread`（卖出对称）
- **强制成交**（卖点/清仓）：`limit=bid/ask` 起步；每 5s 跳 1 tick，最多 3 tick；仍未成 → 改 `L_mkt`
- **TTL**：每单 30s；若信号仍有效 **仅一次**重发（总 2 次尝试）

### 5.2 撮合规则（简化）

- LMT 买：`limit≥ask` → 成交价=ask；若 `mid<limit<ask & limit≥ask-0.1*spread` → 视作成交（近似 Adaptive）
- LMT 卖：对称
- **价差异常**：`spread>max($0.10,5%*mid)` → 不下单（记录 `BLOCK_BY_LIQ`）
- 支持**部分成交**

------

## 6) 期权选择与路径

- 规则：**DTE 2–7、OTM +2~+5**（可选 `Δ≈0.35–0.45`）；
- 若存在 `bars1m_option`：用该合约 bid/ask/mid/iv/delta 模拟成交与 PnL；
- 若不存在：**保守跳过**（记录 `NO_OPTION_SERIES`）；不做价格近似

------

## 7) 成本模型

- **滑点**：买入 `slip=fill-mid_at_submit`；卖出 `slip=mid_at_submit-fill`；容忍上限 `≤0.35*spread+$0.03`
- **费用**：以 IB 美股期权默认费率常量计入每笔
- **流动性**：`OI≥500`、`Vol≥100`、`spread≤max($0.10,5%*mid)` 不满足 → `BLOCK_BY_LIQ`

------

## 8) 指标与度量（扩充：固定窗口 + TFE）

- 固定窗口收益：`RET_SIG_*_(5M|15M|30M|60M)`
- TFE（Time-For-Event）：
  - `RET_SIG_*_TFE_MEAN`、`RET_SIG_*_TFE_P50`、`RET_SIG_*_TFE_P90`
  - 统计信号触发后达到目标事件（如回到中轨/上轨/固定收益阈）的时间与收益
- 事件计数：`COUNT_EXEC_SIG_*_(FIXED|TFE)`、`COUNT_OPP_SIG_*_TFE`


------

## 8) 风控约束（回放内生，含新增逻辑）

- **硬规则**：−8%止损、12–14 禁开、14:00 清“开盘追高”、VIX≥20 关 E1、IV>100% 禁隔夜、AM 卖点优先
- **逐标的封禁**：
  - **MIDFAIL**：开盘≤15m **急跌触中轨**且 **10m 内未回中轨之上** → **Block-Until-14:00**
  - **MISSED_ENTRY**：09:31 的 E1/E2 **TTL 到期未成交**（或被风控拒绝）→ **当日禁开**（或 Block-Until-14:00，按参数）
- **事件日**：**财报前 3–5 日做 T** 必须 `M60 上行` **或** `ATR%<阈值`（默认 2%）；不满足 → 阻断 BUY 类信号
- **A1 Gate**：A2/A3/A4 评估前必须通过 A1（时间/位置/资格/高开限制）

> 上述封禁/事件日/A1 在回测中作为**前置判断**实现，确保与实盘风控一致

------

## 9) 结果落库（与现有表一致）

- **`bt_runs`**：`run_id, mode, start_date, end_date, universe, params_json, created_at`
- **`bt_trades`**：`run_id, symbol, conid, open_ts, close_ts, side, qty, open_px, close_px, fees, pnl, mfe, mae, exit_reason, signal_code`
- **`bt_signals`**：`run_id, ts_end, symbol, signal_code, accepted, reason`（包含 `BLOCK_BY_LIQ/MIDFAIL/MISSED_ENTRY/PRE_EARN.../A1_GATE` 等）
- **`bt_metrics_daily`**：`run_id, trade_date, gross_pnl, net_pnl, num_trades, win_rate, avg_win, avg_loss, exp_value, max_dd`
- **`bt_metrics_total`**：聚合总览（Sharpe/Sortino/MaxDD/WinRate/PF 等）

------

## 10) 绩效指标（分总览 / 分解 / 稳定性）

- **总览**：收益曲线、年化收益/波动、Sharpe/Sortino、最大回撤、胜率、PF
- **分解**：按子策略（E1/E2/A2/A3/A4/S1/S2/OVERNIGHT）、时段（开盘段/上午/午后）、VIX Regime、流动性分层（按 `spread` 桶）
- **稳定性**：参数小扰动（`BOLL k:1.8–2.2`、`ATR 轻反弹系数:0.4–0.6`、`RVOL 双峰阈:2.5–3.5`）；样本外（时间切分）

------

## 11) 参数与开关（回放可控）

- `ttl_buy=180s`，`cooldown_buy=600s`
- `feature.mfi_stoch_filter=false`（E1/E2 附加过滤）
- 封禁：`enable_midfail_block=true`，`missed_entry_block='close'|'14:00'`（默认 `'close'`）
- 事件日：`preearn_days_min=3`、`preearn_days_max=5`、`preearn_atr_pct_max=0.02`
- 期权选择与流动性：`min_oi=500`、`min_vol=100`、`max_spread = max($0.10,5%*mid)
 - 早盘新增：`am_bottom.*`、`am_sell1.*`、`am_conf.*`、`overnight.*`、`gate.vix.*`

------

## 12) 运行方式与 CLI

1. 准备 `.env`（复制 `.env.example` 并配置 TimescaleDB、Redis、风险服务等真实地址）。
2. 保持 TimescaleDB 仅作为数据源，回测不会加载 CSV 或本地快照。
3. 通过 CLI 启动（Universe 默认 `ref_market_cap:GLOBAL`，无需手动列出 symbol）：

   ```bash
   python -m apps.backtest.main \
     --start 2024-01-02T09:30:00-05:00 \
     --end   2024-01-05T16:00:00-05:00 \
     --universe ref_market_cap:GLOBAL \
     --signal-mode recompute \
     --risk-mode inproc
   ```

   - 可选 `--symbols TSLA NVDA` 作为调试覆盖，限制 Universe；默认按 TimescaleDB 的市值/白名单自动筛选。
   - `start` / `end` 必须为带时区的 ISO8601；默认 `mode=logic`。
   - `signal-mode=recompute` 将现场重算信号；`db` 模式直接复用 `bt_signals`。
   - `risk-mode=http` 需确保 `RISK_SERVICE_URL` 指向可用的风控服务。
4. 运行完成后，在 TimescaleDB 中查询 `bt_runs / bt_trades / bt_signals / bt_metrics_* / bt_top5` 即可验证结果。
