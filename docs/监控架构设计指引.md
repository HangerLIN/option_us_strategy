### 0) 预备与原则
- 开关与标签
  - MONITORING_ENABLED=true|false（默认 false）
  - MONITORING_PORT=9100..9199（每进程不同）
  - MONITORING_ENV=paper|live
- 变更原则
  - 仅“埋点+暴露指标端点+配置”三类改动；无 schema 变更，无业务逻辑分支变化。
  - 新代码全部由 MONITORING_ENABLED 控制，置 false 时行为与现状一致。

### 1) 依赖与服务暴露
- 安装依赖（如未安装）
  - pip install prometheus_client
- FastAPI 服务确认 /metrics
  - 已有：signal_svc、risk_svc、exec_svc、pnl_svc、backtest 均有 /metrics
  - 待确认/补充：
    - md_gw：若无 /metrics，新增 FastAPI 路由:

### 2) 按服务启用埋点（全部加开关）
- md_gw（apps/md_gw/main.py）
  - 连接/重连回调：
    - set_ibkr_connection_status(connected: bool) → rt_ibkr_connection_status
    - record_ibkr_reconnection(reason: str) → rt_ibkr_reconnections_total
  - tick 回调（必要即可，避免高基数）
    - record_tick_received(symbol) → rt_ticks_received_total
  - 订阅变更：
    - set_subscribed_symbols_count(count) → rt_subscribed_symbols_count
  - 分钟闭合/入库完成：
    - observe_bar_latency(latency) → bars_latency_seconds
    - set_cached_bars_count(symbol, "1m", count) → rt_cached_bars_count
  - Top5 任务：
    - set_top5_candidates_count(n) → rt_top5_candidates_count
    - with timer → observe_top5_calculation(sec) → rt_top5_calculation_seconds
    - record_top5_selection() → rt_top5_selection_total
- rt_engine（apps/rt_engine/aggregator.py）
  - 指标计算包裹：
    - with observe_indicator_calculation("boll|rsi|atr|..."): 计算主体 → rt_indicator_calculation_seconds
    - 异常捕获 → record_indicator_failure(indicator, reason) → rt_indicator_failures_total
  - 数据新鲜度任务（每 15s）：
    - last_bar_ts_diff_seconds.set(now() - max(ts_end))
- signal_svc（apps/signal_svc/engine.py）
  - 每分钟生成入口/主循环计时：
    - observe_signal_generation(sec) → signal_generation_latency_seconds
  - 信号产出：
    - record_signal_emitted(signal_code) → signals_emitted_total{signal_code}
  - 被过滤：
    - record_signal_filtered(reason) → signals_filtered_total{reason}
- risk_svc（apps/risk_svc/service.py 或 main）
  - 组合/市场态：
    - set_kill_switch_state(active) → risk_kill_switch_state
    - set_risk_vix(v) → risk_vix_last
    - set_risk_used_r(v)、set_risk_drawdown(v)
  - 规模/限额（如已计算）：
    - set_position_count(n)、set_total_exposure(usd)、set_capital_utilization(pct)
    - set_limit_usage(limit_type, pct)、record_limit_approaching(limit_type, threshold)
  - 事件：
    - record_risk_block(reason_code) → risk_block_events_total
    - record_force_close(reason_code) → risk_force_close_total
- exec_svc（apps/exec_svc/main.py）
  - 订单漏斗（提交/通过/阻断三处调用）：
    - record_order_submission(mode) / record_order_accept(mode) / record_order_block(stage, reason_code)
    - 自动维护 orders_conversion_rate
  - 成交延迟：
    - observe_order_execution_latency(stage, sec) → order_execution_latency_seconds{stage}
  - 超时：
    - record_order_timeout(timeout_type) → orders_timeout_total
- pnl_svc（apps/pnl_svc/consumer.py）
  - 成交或行情刷新：
    - set_realized_pnl_today、set_unrealized_pnl_today、set_cumulative_pnl
    - set_trades_count_today、set_win_rate

提示：所有调用处外侧加 if MONITORING_ENABLED: 防护；或封装成 no-op 包装器按开关返回空实现。

### 5) 告警规则（核心版，追加）
将规则文件追加到 infra/prometheus/rules/data_ingest.yml 或新建 trading_core.yml：
```yaml
groups:
- name: trading-core
  rules:
  - alert: MdGwOffline
    expr: rt_ibkr_connection_status == 0
    for: 60s
    labels: {severity: critical}
    annotations: {summary: 'IBKR disconnected'}

  - alert: BarsLatencyStuck
    expr: histogram_quantile(0.95, sum(rate(bars_latency_seconds_bucket[5m])) by (le)) > 5
    for: 5m
    labels: {severity: critical}
    annotations: {summary: '1m bar processing P95 > 5s'}

  - alert: KillSwitchOn
    expr: risk_kill_switch_state == 1
    for: 1m
    labels: {severity: critical}
    annotations: {summary: 'Kill switch active'}

  - alert: ForceCloseSpike
    expr: increase(risk_force_close_total[15m]) > 3
    for: 0m
    labels: {severity: high}

  - alert: LowOrderConversionLive
    expr: orders_conversion_rate < 0.4
    for: 5m
    labels: {severity: high, env: live}
```

### 7) 灰度与验证
- 阶段 A（无侵入验证）
  - MONITORING_ENABLED=false，仅配置 Prometheus/Grafana，不抓取 aggregator
  - 检查现有服务 /metrics 可读、Grafana 能显示静态面板
- 阶段 B（读路径开启）
  - MONITORING_ENABLED=true（paper 环境）
  - 打开 signal_svc、risk_svc、exec_svc、pnl_svc 埋点；md_gw /metrics；聚合器 start_http_server
  - 验证关键指标是否更新：bars_latency_seconds、signals_emitted_total、orders_conversion_rate、risk_kill_switch_state
- 阶段 C（告警与阈值）
  - 打开 Alertmanager 路由，但限制只发到测试频道；观察 1-2 个交易日
  - 调整噪声（为聚合器与 md_gw 指标加 rate/阈值）

### 8) 回滚与安全网
- 任一服务：将 MONITORING_ENABLED=false 立即回到原状；Prometheus 抓取将看到旧值或空值，不影响业务逻辑
- Prometheus/Grafana/Alertmanager 全部为旁路服务，停止不影响交易流程
