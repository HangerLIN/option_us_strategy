## 📋 手动步骤（如果需要）

### 1. 安装软件

```bash
# 安装Prometheus
brew install prometheus

# 安装Grafana
brew install grafana

# 安装Alertmanager（可选）
brew install alertmanager
```

### 2. 配置文件

```bash
cd /Users/hangerlin/Desktop/option_us_strategy/infra

# 创建配置目录
mkdir -p ~/prometheus/rules ~/prometheus/data
mkdir -p ~/alertmanager/data

# 复制配置
cp prometheus/prometheus_local.yml ~/prometheus/prometheus.yml
cp prometheus/rules/*.yml ~/prometheus/rules/
cp alertmanager/alertmanager.yml ~/alertmanager/alertmanager.yml
```

### 3. 配置Grafana

```bash
# 创建provisioning目录
mkdir -p /opt/homebrew/etc/grafana/provisioning/datasources
mkdir -p /opt/homebrew/etc/grafana/provisioning/dashboards

# 配置数据源（Prometheus数据源会自动配置）
# 看板会自动从 infra/grafana/dashboards/ 加载
```

### 4. 启动服务

```bash
# 启动Prometheus
brew services start prometheus

# 启动Grafana
brew services start grafana

# 启动Alertmanager（如果安装了）
brew services start alertmanager
```

## 🔧 常用命令

### 服务管理

```bash
# 启动所有服务
brew services start prometheus
brew services start grafana
brew services start alertmanager

# 停止所有服务
brew services stop prometheus
brew services stop grafana
brew services stop alertmanager

# 重启服务（修改配置后）
brew services restart prometheus
brew services restart grafana

# 查看状态
brew services list
```

### 查看日志

```bash
# Prometheus日志
tail -f /opt/homebrew/var/log/prometheus.log

# Grafana日志
tail -f /opt/homebrew/var/log/grafana/grafana.log
```

### 热更新配置

```bash
# Prometheus配置热更新（无需重启）
curl -X POST http://localhost:9090/-/reload

# Grafana需要重启
brew services restart grafana
```

## 🐛 故障排查

### 问题：Prometheus无法启动

```bash
# 检查配置文件
promtool check config ~/prometheus/prometheus.yml

# 检查端口占用
lsof -i :9090

# 查看详细日志
tail -f /opt/homebrew/var/log/prometheus.log
```

### 问题：Grafana无法访问

```bash
# 检查服务状态
brew services list | grep grafana

# 检查端口
lsof -i :3000

# 重启Grafana
brew services restart grafana
```

### 问题：看板显示"No Data"

**原因**: 业务服务还没启动或Prometheus无法访问

**解决**:
1. 启动业务服务
2. 检查服务是否暴露 `/metrics` 端点
3. 在Prometheus中查看Targets状态
4. 确认时间范围选择正确

### 问题：无法抓取业务服务指标

```bash
# 1. 确认服务正在运行并暴露metrics
curl http://localhost:8002/metrics

# 2. 检查Prometheus配置
cat ~/prometheus/prometheus.yml | grep -A 5 "rt_engine"

# 3. 查看Prometheus日志中的错误
tail -f /opt/homebrew/var/log/prometheus.log | grep -i error
```
